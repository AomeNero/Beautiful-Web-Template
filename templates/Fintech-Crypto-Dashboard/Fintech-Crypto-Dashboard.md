# Fintech Crypto Dashboard

> 来源：[uupm.cc/demo/fintech-crypto](https://www.uupm.cc/demo/fintech-crypto)

## 基本信息

| 属性 | 值 |
|------|-----|
| 风格ID | `fintech-crypto-dashboard` |
| 显示名称 | Fintech Crypto Dashboard |
| 模式 | 🌙 深色模式 (Dark OLED) |
| 字体类型 | sans-serif |
| 描述 | 金融科技加密交易仪表盘，深蓝 OLED 背景搭配霓虹绿/蓝渐变，玻璃拟态导航与网格背景，专业级数据可视化风格。 |

## 设计哲学

- **核心原则**：受专业加密货币交易平台（如 Coinbase、Binance）启发的金融科技美学。深色 OLED 画布搭配高对比霓虹色数据可视化，传递信任感与科技感。
- **气质**：专业、安全、高效。少一些"消费级"，多一些"机构级"。

## 设计 Token 系统（DNA）

### 色彩系统

- **背景**：`#0A0E27`（深空蓝黑）— 主画布
- **表面**：`#0F1635`（稍浅的深蓝）— 卡片/面板背景
- **表面悬浮**：`rgba(15, 22, 53, 0.8)` — 玻璃态叠加
- **边框**：`rgba(30, 38, 80, 0.5)` — 含蓄分隔线
- **主文字**：`#FFFFFF` — 主要标题与数据
- **次要文字**：`#8B92B3` — 描述性文字
- **强调绿**：`#39FF14`（霓虹绿）— 涨幅、CTA、活跃状态
- **强调蓝**：`#0080FF`（电光蓝）— 渐变起点、链接
- **渐变**：`linear-gradient(135deg, #0080FF, #39FF14)` — 蓝绿渐变
- **危险/跌幅**：`#FF4444` — 红色跌幅指示

### 字体

- **标题字体**：`Space Grotesk`（几何无衬线，科技感）
- **正文字体**：`Inter`（清晰可读，数据友好）
- **标题字重**：`600-700`，紧凑字距
- **正文字重**：`400-500`

### 圆角

- **卡片**：`12px` — 标准卡片圆角
- **按钮**：`8px` — 按钮圆角
- **大容器**：`16px` — 大面板圆角
- **胶囊**：`9999px` — 标签/徽章

### 阴影

- **卡片阴影**：`rgba(0, 0, 0, 0.4) 0px 4px 6px -1px, rgba(0, 0, 0, 0.3) 0px 2px 4px -2px`
- **蓝色辉光**：`rgba(0, 128, 255, 0.3) 0px 0px 20px 0px` — 强调元素发光

### 间距

- **区块间距**：`80px`（垂直）
- **容器内边距**：`32px`（水平）
- **卡片间距**：`24px`
- **元素间距**：`16px` / `8px`

### 特效

- **背景网格**：`linear-gradient(rgba(30, 38, 80, 0.3) 1px, transparent 1px)` — 1px 网格线
- **玻璃模糊**：`backdrop-filter: blur(12px)` / `blur(20px)`
- **辉光模糊**：`filter: blur(128px)` — 背景光晕

## 组件样式

### 导航栏
- 固定顶部，`backdrop-filter: blur(12px)` 玻璃效果
- 半透明深蓝背景 `rgba(10, 14, 39, 0.8)`
- 底部 1px 边框分隔

### 按钮
- **主 CTA**：霓虹绿背景 `#39FF14`，深色文字，`8px` 圆角
- **次要**：透明背景 + 边框，白色文字
- **悬停**：轻微上移 + 阴影增强

### 卡片
- 深蓝表面 `#0F1635`，`12px` 圆角
- 含蓄边框 `rgba(30, 38, 80, 0.5)`
- 图标使用蓝绿色调

### 数据图表
- SVG 折线图，绿色渐变填充
- 时间范围选择器（1W/1M/1Y）
- 浮动价格标签卡片

### 统计数字
- 渐变文字效果（蓝→绿）
- 大号字重 `700`
- 下方小字标签

## 非通用性（"大胆"要素）

- **网格背景**：整个页面铺满微妙的 1px 网格线，营造技术图纸感
- **霓虹色数据**：涨幅/关键数据使用高饱和霓虹绿，在深色背景上极为醒目
- **浮动图表卡片**：Hero 区域的 BTC 图表卡片带有轻微倾斜和悬浮效果
- **渐变文字标题**：关键标题使用蓝绿渐变填充

## 页面结构

1. **导航栏** — Logo + 导航链接 + Sign In / Get Started
2. **Hero 区域** — 大标题 + 副标题 + CTA 按钮 + BTC 图表卡片 + 加密货币行情条
3. **特性网格** — 6 个特性卡片（Instant Trades, Cold Storage, Advanced Charts, Multi-Wallet, API Access, Fiat On-Ramp）
4. **数据统计** — 4 个关键指标（$12B+, 2M+, 150+, 99.99%）
5. **安全特性** — 左侧文字列表 + 右侧安全仪表盘
6. **CTA 区域** — "Start Trading in Minutes" + 双按钮
7. **页脚** — 多列链接 + 应用下载 + 版权信息

## 效果与动画

- **过渡**：平滑过渡 `0.3s ease`
- **悬停**：卡片轻微上移 + 阴影加深
- **按钮**：悬停时上移 `translateY(-2px)`

## 实现说明

- 使用 CSS 自定义属性管理所有 Token
- 深色模式为唯一模式（无浅色切换）
- 网格背景使用 CSS `linear-gradient` 实现
- 图表使用 SVG 内联绘制
- 响应式断点：`1024px` / `768px`
