# 设计风格：CEX-Trading

## 设计哲学

### 核心原则

CEX-Trading 风格追求**专业金融交易平台的安全感与可信赖感**。它以深空暗色 (#0B0E11) 为画布，用品牌金黄色 (#F0B90B) 作为视觉焦点和 CTA 主色，配合绿色 (#0ECB81) 和红色 (#F6465D) 的涨跌语义色，营造专业、安全、高效的加密货币交易体验。设计拒绝花哨装饰，每个视觉元素都服务于"数据清晰"和"操作直观"两个核心目标。

### 视觉气质

**情感关键词**：
- *专业可信* — 深色背景传递稳定感，金黄色品牌色暗示财富与价值
- *数据驱动* — JetBrains Mono 等宽字体用于所有数值，绿色/红色语义色清晰传达涨跌
- *高效简洁* — 克制的配色和清晰的层级让交易操作一目了然

**此设计不是什么**：
- 不是 DeFi 协议的霓虹渐变赛博风格
- 不是传统银行网站的保守灰蓝配色
- 不是社交应用的活泼多彩设计

### 此风格的 DNA

#### 1. 金黄品牌色签名
#F0B90B 金黄色贯穿整个设计——用于 CTA 按钮、标题高亮、logo 图标、认证数据数值。这是品牌识别的核心，暗示财富与价值。

#### 2. 深空暗色基底
背景色 #0B0E11（近黑）作为主画布，配合 #181A20 的卡片表面和 #1E2329 的表格行，创造层次分明的暗色空间。

#### 3. 涨跌语义色系统
绿色 #0ECB81 表示上涨/买入，红色 #F6465D 表示下跌/卖出，在所有数据展示中保持一致的语义编码。

#### 4. 等宽数据字体
JetBrains Mono 用于所有价格、涨跌幅、交易量等数值显示，创造专业的金融数据终端质感。

#### 5. 交易小部件 UI
Hero 右侧直接展示产品交易界面（价格图表、买卖盘口、操作按钮），用真实产品 UI 作为视觉主体而非抽象插图。

## 设计 Token 系统（DNA）

### 色彩策略

**色彩聚焦**：深空暗色基底 + 金黄品牌色 + 绿/红涨跌语义色。整体为冷暗色调，金黄色提供品牌识别和视觉焦点，绿色/红色用于数据语义。

| `background` | `#0B0E11` | 页面主背景，深空暗色 |

| `surface` | `#1E2329` | 卡片、表格行表面 |

- **区块间距**：垂直内边距 64-96px，区块间交替背景色

## "大胆要素"（签名元素）

1. **金黄品牌色聚焦**：#F0B90B 金黄色仅用于关键 CTA 和标题高亮，在暗色背景上形成强烈视觉焦点，暗示财富与价值。

2. **涨跌语义色系统**：绿色 #0ECB81 / 红色 #F6465D 在所有数据展示中保持一致的语义编码，用户一眼即可判断涨跌方向。

3. **等宽数据字体**：JetBrains Mono 用于所有价格、涨跌幅、交易量数值，创造专业的金融数据终端质感，与 DM Sans 标题形成字体对比。

4. **交易小部件 UI**：Hero 右侧直接展示产品交易界面（走势图、买卖盘口、操作按钮），用真实产品 UI 作为视觉主体，传递"这就是你的交易界面"的直观感受。

5. **认证数据栏**：Security 区底部的 SOC 2 / ISO 27001 / $1B+ / 0 四项认证数据以金黄色数值展示，用权威认证建立用户信任。

## 效果与动画

**运动哲学**：克制而专业。以微妙的入场动画和悬停过渡为主，避免过度动效干扰金融产品的专业感。

**过渡默认**：
- 标准：`0.2s cubic-bezier(0.4, 0, 0.2, 1)`
- 入场：IntersectionObserver 触发，20px 位移 + 透明度渐变，支持 0.1-0.4s 延迟阶梯
- 悬停：按钮背景色变化 + 轻微上浮（translateY(-1px)），卡片边框变色 + 上浮（translateY(-4px)）

**持续动画**：无持续动画，保持金融产品的静态专业感。

## 响应式策略

**断点哲学**：从桌面双栏到移动端单列堆叠，数据表格在移动端保持可读性。

- **Hero**：移动端单列（文案在上、交易小部件在下），桌面端双栏 50:50
- **安全卡片**：移动端单列，平板 2 列，桌面 4 列
- **认证栏**：移动端 2 列，桌面 4 列
- **Footer**：移动端 2 列，桌面 5 列

**关键适配**：
- 标题尺寸：`clamp(28px, 7vw, 60px)`
- 间距缩减：移动端区块间距 48px，桌面 96px
- 表格：移动端缩小字体和图标尺寸

## 可访问性与最佳实践

**色彩对比**：白色文字在 #0B0E11 背景上对比度 > 15:1，满足 WCAG AAA。金黄色 #F0B90B 在暗色背景上对比度约 8:1，满足 WCAG AA。

**聚焦状态**：输入框聚焦时边框变为金黄色，提供清晰的视觉反馈。

**触控目标**：按钮最小高度 44px，Trade 按钮 36px 但点击区域充足。

**运动**：`prefers-reduced-motion: reduce` 时禁用所有动画和过渡，仅保留必要状态变化。

## 实现说明

- **组件结构**：单文件 HTML，零构建依赖。使用 CSS 自定义属性实现主题化。
- **CSS 自定义属性**：所有颜色、间距、圆角、阴影均定义为 `:root` 变量，支持暗色/亮色主题切换。
- **字体加载**：Google Fonts CDN 加载 DM Sans (400, 500, 700) 和 JetBrains Mono (400, 500, 700)。
- **动画库**：纯 CSS 动画 + IntersectionObserver 入场，无需外部库。
- **主题切换**：通过 `data-theme` 属性切换暗色/亮色主题，JavaScript 控制切换逻辑。
