# 高保真 Educational Platform 设计系统

## 设计哲学

**核心概念：积木式学习乐园**
此设计系统将教育平台包装为一个**友好、可触摸的数字积木世界**。每个 UI 元素都像一块精心打磨的彩色积木——圆润、厚实、可堆叠。它拒绝冷峻的企业感，转而追求温暖、活泼、可信赖的学习社区氛围。

**"积木"之别**：
不同于通用 Claymorphism 的"充气玩具"感，此设计更强调**块面堆叠**与**硬偏移阴影**。元素不像漂浮的黏土球，而像桌面上整齐排列的彩色积木块——有重量感、有秩序、有童趣但不幼稚。

*   **材质性**：想象磨砂质感的彩色塑料积木或软木方块。表面哑光但不粗糙，边缘圆润但不模糊。每个块面有明确的边界与厚度。
*   **光照**：光源来自左上方，在每个积木块的右下方投射清晰的硬阴影。阴影不是柔和弥散的，而是有明确边界的偏移投影，模拟真实积木在桌面上的投影效果。
*   **阴影架构**：每个元素使用双层阴影：
    - **外阴影**：4-6px 偏移的深色硬投影，定义元素与背景的分离
    - **内高光**：微妙的顶部/左侧内阴影，模拟光照反射

**感官气质**：
*   **活泼与友好**：界面通过薄荷绿主调与粉彩辅助色（粉色、浅蓝、淡紫）散发活力。它感觉安全、欢迎、鼓励探索——如儿童教育应用的界面。
*   **块面与秩序**：元素以清晰的网格排列，每个"积木"有明确的边界。圆角统一（16-20px），阴影方向一致，创造视觉秩序感。
*   **温暖与可信赖**：暖白背景（#FFF9F5）比纯白更柔和，搭配深色文字（#1E293B）确保可读性。绿色 CTA 传递"开始行动"的积极信号。
*   **教育专业感**：尽管视觉活泼，排版层级清晰、信息密度适中、导航简洁，保持教育平台应有的专业可信度。

**"积木"物理引擎**：
1.  **堆叠（Stack）**：元素像积木一样堆叠在页面上。卡片有明确的底部阴影，模拟放在"桌面"上的效果。
2.  **偏移（Offset）**：阴影向右下方偏移 4-6px，创造积木块的厚度感。这不是柔和的弥散阴影，而是有明确边界的投影。
3.  **圆角（Rounded）**：所有元素使用 16-20px 圆角，消除锐利感但保持块面特征。
4.  **色彩编码（Color-coded）**：不同功能区域用不同颜色标识——绿色用于 CTA 和成功状态，粉色用于徽章和装饰，浅蓝用于次级按钮和背景区块。

## 设计 Token 系统

### 色彩（"积木乐园"调色板）

**Background**：
*   **主画布**：`#FFF9F5`（暖奶油白）。比纯白更温暖，营造舒适学习氛围。
*   **区块背景**：`#ADD8E6`（浅天蓝）。用于 CTA 全宽背景区块，与暖白形成柔和对比。
*   **卡片背景**：`#FFFFFF`（纯白）。内容卡片使用纯白，在暖白画布上微微凸起。

**Foreground**：
*   **文字（主要）**：`#1E293B`（深石板灰）。高对比度，确保可读性。
*   **文字（次要）**：`#64748B`（中石板灰）。用于描述文字和次要信息。
*   **文字（导航）**：`#475569`（石板灰）。导航链接使用此色。

**点缀（鲜艳但柔和）**：
*   **主色（绿色）**：`#22C55E`（薄荷绿）。用于主要 CTA 按钮、强调文字、进度条、徽章指示器。
*   **次色（粉色）**：`#FDBCB4`（柔和粉）。用于图标容器背景、徽章背景。
*   **三色（浅蓝）**：`#ADD8E6`（天蓝）。用于次级按钮背景、CTA 区块背景。
*   **四色（淡紫）**：`#E6E0F8`（淡薰衣草）。用于图标容器背景。
*   **五色（薄荷）**：`#98FF98`（薄荷绿）。用于图标容器背景。
*   **深色（深蓝灰）**：`#2D3748`（深蓝灰）。用于阴影和边框。

**渐变策略**：
*   **按钮**：纯色填充，不使用渐变。绿色按钮 `#22C55E`，浅蓝按钮 `#ADD8E6`。
*   **图标容器**：纯色背景，不同功能用不同颜色区分。
*   **文字高亮**：Hero 标题中 "Anytime" 用绿色 `#22C55E` 强调。
*   **进度条**：绿色 `#22C55E` 填充，浅灰 `#E2E8F0` 轨道。

### 字体

**字体选择**：
*   **标题**：**Fredoka**（Google Fonts，字重：400/500/600/700）。圆润、友好的无衬线字体，完美匹配积木美学。
*   **正文**：**DM Sans**（Google Fonts，字重：400/500/700）。几何、干净、高可读性。

**层级**：
*   **Hero 标题**：`48-64px`，Fredoka 700，紧凑字距，行高 1.1-1.2。
*   **区块标题**：`32-40px`，Fredoka 700，行高 1.2。
*   **卡片标题**：`18-20px`，Fredoka 600-700。
*   **正文**：`15-16px`，DM Sans 400-500，行高 1.6-1.7。
*   **小文字**：`13-14px`，DM Sans 400-500。用于标签、元信息、导航。
*   **统计数字**：`28-32px`，Fredoka 700。

### 形状与圆角

**"圆角积木"规则**：
*   **大容器/卡片**：`20px` 圆角
*   **按钮**：`16px` 圆角
*   **图标容器**：`12-14px` 圆角
*   **徽章/胶囊**：`999px`（全圆角胶囊）
*   **导航栏**：`20px` 圆角
*   **社交图标**：`12px` 圆角方块

**关键规则**：
*   所有元素必须有圆角，最小 `12px`。
*   保持一致性：同层级元素使用相同圆角值。
*   徽章和胶囊使用完全圆角（pill shape）。

### 阴影（积木的厚度）

**1. 积木卡片阴影**：
用于内容卡片和导航栏。
```css
box-shadow: 4px 4px 0px #2D3748;
```

**2. 积木按钮阴影**：
用于 CTA 按钮。
```css
box-shadow: 4px 4px 0px #1a6b3c; /* 绿色按钮用深绿色阴影 */
box-shadow: 4px 4px 0px #7fb3c9; /* 浅蓝按钮用深蓝色阴影 */
```

**3. 积木按压状态**：
按钮激活时阴影减小，模拟按下效果。
```css
box-shadow: 2px 2px 0px #1a6b3c;
transform: translate(2px, 2px);
```

**4. 卡片悬停阴影**：
卡片悬停时阴影增强。
```css
box-shadow: 6px 6px 0px #2D3748;
transform: translateY(-2px);
```

## 动画系统

**1. 按钮悬停抬升**：
```css
transition: all 0.2s ease;
hover: translateY(-2px);
```

**2. 按钮按压**：
```css
active: translate(2px, 2px);
active: shadow 减小;
```

**3. 卡片悬停**：
```css
transition: all 0.3s ease;
hover: translateY(-4px);
hover: shadow 增强;
```

**4. 浮动装饰元素**：
```css
@keyframes float {
  0%, 100% { transform: translateY(0) rotate(0deg); }
  50% { transform: translateY(-10px) rotate(5deg); }
}
```

## 响应式策略

**断点**：
*   **桌面**：`>= 1024px` — 完整布局
*   **平板**：`768px - 1023px` — 两列网格，缩小间距
*   **移动**：`< 768px` — 单列堆叠，全宽按钮

**字体缩放**：
*   Hero 标题：`36px (移动) → 48px (平板) → 64px (桌面)`
*   区块标题：`28px (移动) → 32px (平板) → 40px (桌面)`

**布局变换**：
*   **导航**：移动端隐藏非必要链接，显示汉堡菜单
*   **Hero**：移动端垂直堆叠，桌面端双栏
*   **特性**：移动端单列 → 平板两列 → 桌面四列
*   **Footer**：移动端单列堆叠 → 桌面四列

**组件调整**：
*   按钮：移动端全宽 `w-full`
*   卡片：移动端减少内边距
*   圆角：所有断点保持一致

## 该做与不该做

*   **该做** 使用硬偏移阴影（4px 4px 0px）而非柔和弥散阴影。
*   **该做** 所有元素使用圆角，最小 12px。
*   **该做** 绿色（#22C55E）用于主要 CTA 和成功状态。
*   **该做** Fredoka 用于所有标题，DM Sans 用于正文。
*   **该做** 暖白背景（#FFF9F5）而非纯白。
*   **不该做** 使用锐角或小于 12px 的圆角。
*   **不该做** 使用柔和弥散阴影（box-shadow 带大 blur radius）。
*   **不该做** 使用渐变按钮——使用纯色填充。
*   **不该做** 文字颜色浅于 #64748B（可读性风险）。
*   **不该做** 按钮高度小于 44px（可访问性）。
