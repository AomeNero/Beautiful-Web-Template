## 布局创意 (Layout Ideas)

### Hero

居中单列布局。顶部"Powered by GPT-4 & Claude"胶囊标签（淡紫色背景），超大标题"Your AI Assistant for Everything"其中"Everything"使用靛蓝渐变文字，副标题描述，双 CTA 按钮（实心主按钮 + 描边次按钮），下方为内嵌式聊天界面预览卡片。

### Chat Interface

Hero 区下方直接嵌入聊天界面预览。白色卡片带阴影，顶部含头像+名称+在线状态，消息气泡左右交替（用户蓝气泡右对齐，AI 灰色气泡左对齐），底部输入框+发送按钮。

### Features

三列特性卡片网格，每张卡片带图标容器、标题和描述文字。白色背景，简洁布局。

### Demo / How It Works

深色背景区块，展示 AI 对话示例或功能演示。白色内容卡片带圆角，内部含列表、说明文字等。

### Integrations

"Integrates with Your Stack"标题区，"Stack"使用靛蓝渐变。4x2 集成平台图标网格（Slack、Discord、Notion、GitHub、Zapier、Vercel、AWS、Google），每个图标卡片带圆角边框。

### Code Block

终端风格代码展示区，深色背景（#1a1a2e），圆角顶部含红/黄/绿交通灯按钮和文件名，代码使用等宽字体语法高亮。

### Pricing

三列定价卡片网格，中间"Pro"档位高亮（靛蓝边框+渐变背景），含价格、特性列表和 CTA 按钮。

### CTA Banner

全宽靛蓝渐变背景横幅，白色文字"Ready to Build with AI?"，双 CTA 按钮（白色实心+描边），底部小字说明。

### Footer

深色背景（#111827），多列链接布局（Product、Resources、Company、Legal），左侧 Logo+描述+社交图标，底部版权信息和系统状态指示。

## 完整提示词 (Full Prompt)

# 设计风格：AI-Chatbot-Platform / AI 原生极简

## 设计哲学

**核心原则**：将 AI 对话体验置于设计中心，以极简主义为框架，让智能感自然流露。这种风格融合了现代 SaaS 的清爽与 AI 产品的未来感——**干净的白色画布**作为基础，**靛蓝/紫色渐变**作为品牌灵魂，**对话式交互**作为核心隐喻。每个元素都应传递"智能、可靠、易用"的感受。

**气质**：智能、现代、清爽、可信、高效、前沿、亲和。

**AI-Chatbot-Platform 的承诺**：这不是一个普通的 SaaS 落地页——它是一个 AI 产品的门面。聊天界面本身就是 Hero 视觉，用户无需滚动即可理解产品核心价值。蓝渐变不只是装饰，而是"AI 智能"的视觉编码。

## 设计 Token 系统（DNA）

### 色彩系统（AI 智能蓝）

**基础色**：
- **background**：`#F5F5F5`（浅灰白）— 页面底色，柔和不刺眼
- **backgroundAlt**：`#FFFFFF`（纯白）— 卡片、内容区背景
- **foreground**：`#0F172A`（深石板）— 主要文字，高对比度
- **muted**：`#64748B`（石板灰）— 次要文字、描述
- **border**：`#E2E8F0`（淡灰蓝）— 细腻边框与分隔符
- **borderLight**：`#E5E7EB`（更淡灰）— 轻量分隔

**品牌色**：
- **primary**：`#6366F1`（靛蓝）— 主品牌色，按钮、链接、高亮
- **primaryHover**：`#5865F2`（靛蓝深）— 悬停状态
- **primarySoft**：`rgba(99, 102, 241, 0.1)`（淡靛蓝）— 背景点缀、标签
- **primaryGradient**：`linear-gradient(135deg, #6366F1 0%, #8B5CF6 100%)` — 渐变应用

**功能色**：
- **success**：`#10B981`（翡翠绿）— 在线状态、成功指示
- **warning**：`#FF9900`（琥珀）— 警告、注意
- **danger**：`#FF4A00`（橙红）— 错误、危险

**深色区**：
- **darkBg**：`#111827`（近黑）— 页脚、深色区块背景
- **darkSurface**：`#1A1A2E`（深蓝黑）— 代码块背景
- **darkText**：`#FFFFFF`（纯白）— 深色区文字
- **darkMuted**：`#9CA3AF`（灰）— 深色区次要文字

**用色规则**：
1. **对比度**：深色文字对白色背景保持 10:1+，次要文字最低 4.5:1
2. **分层策略**：白色卡片叠加于浅灰底色之上，营造微妙深度
3. **靛蓝应用**：所有主要交互元素（按钮、链接、聚焦环、图标）使用靛蓝
4. **渐变克制**：渐变仅用于 CTA 按钮、标题高亮文字、CTA Banner 背景
5. **深色区块**：页脚和代码展示区使用深色背景，与浅色主体形成节奏

### 字体系统

**字族**：
- **标题字体**：`"Space Grotesk", sans-serif` — 几何感无衬线，现代科技感
- **正文字体**：`"DM Sans", sans-serif` — 圆润友好，高可读性
- **代码字体**：`"IBM Plex Mono", monospace` — 等宽代码展示

**字号阶梯与层级**：
- **展示标题**：`56px-64px`，Space Grotesk，`font-weight: 700`，`line-height: 1.1`
- **区块标题**：`36px-48px`，Space Grotesk，`font-weight: 700`
- **子标题**：`24px-30px`，Space Grotesk，`font-weight: 600`
- **正文**：`16px-18px`，DM Sans，`line-height: 1.7`
- **小字/标签**：`12px-14px`，DM Sans，`font-weight: 500`

**字重分布**：
- 标题：Bold/ExtraBold（600-700）
- 正文：Regular/Medium（400-500）
- 按钮：Medium/SemiBold（500-600）

**特殊排印模式**：
1. **渐变文字**：标题中的关键词使用靛蓝渐变
   ```css
   background: linear-gradient(135deg, #6366F1 0%, #8B5CF6 100%);
   -webkit-background-clip: text;
   -webkit-text-fill-color: transparent;
   ```

2. **胶囊标签**：顶部小标签使用淡紫色背景+靛蓝文字
   ```css
   background: rgba(99, 102, 241, 0.08);
   color: #6366F1;
   border-radius: 999px;
   padding: 6px 16px;
   font-size: 14px;
   ```

### 圆角与边框系统

**圆角值**：
- **按钮/标签**：`12px`（胶囊感圆角）
- **卡片**：`16px`（柔和大圆角）
- **聊天气泡**：`16px 16px 16px 6px`（对话气泡形状）
- **输入框**：`12px`
- **集成图标**：`12px`

**边框样式**：
- **粗细**：标准 `1px`，高亮状态 `2px`
- **颜色**：标准边框 `#E2E8F0`，交互边框 `#6366F1`
- **样式**：实线，无虚线

### 阴影与深度

**阴影哲学**：柔和、克制、真实。阴影用于区分层级而非装饰。

**阴影配方**：

1. **卡片默认**：
   ```
   box-shadow: 0 20px 25px -5px rgba(0, 0, 0, 0.1), 0 8px 10px -6px rgba(0, 0, 0, 0.1);
   ```

2. **按钮悬停**：
   ```
   box-shadow: 0 4px 14px rgba(99, 102, 241, 0.35);
   ```

3. **聚焦环**：
   ```
   box-shadow: 0 0 0 2px rgba(99, 102, 241, 0.5);
   ```

### 纹理与氛围效果

**1. 磨砂玻璃导航**：
- 导航栏使用半透明背景+背景模糊
- 公式：`background: rgba(255, 255, 255, 0.8); backdrop-filter: blur(12px);`
- 底部细边框分隔

**2. 渐变文字**：
- 标题关键词使用靛蓝到紫色渐变
- 作为视觉焦点，引导注意力

**3. 聊天界面模拟**：
- Hero 区直接展示产品核心交互
- 白色卡片+阴影+圆角，模拟真实聊天窗口

## "大胆要素"（非通用性）

这些是定义 AI-Chatbot-Platform 的**强制性标志性元素**：

### 1. **聊天界面即 Hero**
Hero 区必须包含一个模拟聊天界面卡片，展示产品核心交互。这是区别于普通 SaaS 页面的关键。

### 2. **靛蓝渐变文字**
标题中的关键词必须使用靛蓝到紫色渐变（`#6366F1` → `#8B5CF6`），作为视觉焦点。

### 3. **磨砂玻璃导航**
导航栏必须使用半透明背景+背景模糊效果，滚动时保持可见。

### 4. **胶囊标签**
Hero 顶部使用淡紫色背景的胶囊标签展示技术栈信息（如"Powered by GPT-4 & Claude"）。

### 5. **对话气泡形状**
聊天消息使用不对称圆角（`16px 16px 16px 4px`），模拟真实对话气泡。

### 6. **深色页脚对比**
页脚使用深色背景（`#111827`），与浅色主体形成强烈对比，增强视觉节奏。

### 7. **集成平台网格**
展示与主流平台的集成能力，使用品牌色图标+圆角卡片。

### 8. **代码展示区**
终端风格代码块展示 API 使用示例，深色背景+语法高亮。

### 9. **CTA 渐变横幅**
全宽靛蓝渐变背景的行动号召区，白色文字+双按钮。

### 10. **在线状态指示**
聊天界面中展示绿色圆点+在线文字，传递实时感。

## 动画与运动

**运动哲学**：流畅、轻快、响应迅速。AI 产品应感觉即时响应。

**缓动函数**：
- 默认：`ease-out`
- 按钮：`cubic-bezier(0.4, 0, 0.2, 1)`

**时长层级**：
- 快速交互：`150ms`
- 标准过渡：`200ms-300ms`
- 入场动画：`500ms`

**变换模式**：
- 按钮悬停：微上浮 `translateY(-1px)` + 阴影加深
- 卡片悬停：微上浮 `translateY(-2px)` + 阴影
- 链接悬停：颜色变靛蓝

## 反模式（应避免之事）

### 切勿：
1. **使用衬线字体**——这是现代 AI 产品，需要无衬线的清爽感
2. **使用暖色调**——保持冷色调（蓝/紫/灰）的专业感
3. **过度装饰**——极简主义，每个元素都有功能目的
4. **使用纯黑背景**——主体使用浅灰白，仅页脚和代码区用深色
5. **忽略聊天界面**——这是核心差异化元素
6. **使用硬阴影**——阴影必须柔和、自然
7. **圆角过小**——保持 12px+ 的圆角，传递友好感
8. **导航不透明**——必须使用磨砂玻璃效果
9. **渐变滥用**——仅用于关键词和 CTA
10. **忘记响应式**——聊天界面在移动端需适配

## 响应式策略

### 移动端（< 768px）：
- **所有列垂直堆叠**
- **聊天界面全宽**，减小内边距
- **导航简化**为汉堡菜单
- **标题字号缩小**至 36px-42px
- **集成网格**变为 2 列
- **定价卡片**垂直堆叠

### 平板（768px - 1024px）：
- **双列网格**用于特性和集成
- **聊天界面**保持居中，适当缩小
- **导航**可保持完整或简化

### 桌面（> 1024px）：
- **完整三列/四列网格**
- **聊天界面**最大宽度 672px
- **完整导航**和所有装饰元素

## 可访问性考量

### 对比度要求：
- **主要文字对背景**：10:1+（超过 WCAG AAA）
- **次要文字对背景**：最低 4.5:1（达 WCAG AA）
- **靛蓝按钮上的白色文字**：4.6:1（达 WCAG AA）

### 聚焦指示器：
- **始终可见**：2px 靛蓝环
- **高对比**：在所有背景上清晰可见

### 语义化 HTML：
- 使用正确的标题层级
- 导航用 `<nav>`，内容用 `<main>`
- 聊天界面使用适当的 ARIA 标签

## 总结

AI-Chatbot-Platform 风格由**聊天界面即 Hero**、**靛蓝渐变品牌色**、**磨砂玻璃导航**和**深色页脚对比**所定义。

当聊天界面自然融入 Hero 区、蓝渐变恰到好处地点缀关键词、整体感觉清爽而智能时，此风格即告成功。当它感觉像套了蓝色主题的通用 SaaS 页面时，即告失败。

聊天界面是产品的灵魂展示。靛蓝渐变是 AI 智能的视觉编码。磨砂玻璃导航是现代感的签名。三者共同营造出连贯、智能、可信的 AI 产品体验。
