## 布局创意 (Layout Ideas)

### Hero

### Services

三列服务卡片网格，每张卡片顶部有彩色图标（圆形背景），标题 + 描述 + 箭头链接。卡片白色背景，圆角 16px，悬停有轻微上浮效果。

### Doctors

左右分栏：左侧联系信息（电话、地址、邮箱），右侧预约表单（姓名、邮箱、电话、日期、科室选择、备注），底部全宽蓝色提交按钮。

### Footer

# 设计风格：Medical-Clinic

## 设计哲学

### 核心原则

**信任与专业**：以医疗蓝（#0066CC）为主色调，传递可信赖、专业的医疗品牌形象。所有设计决策服务于"让患者感到安心"这一核心目标。

**清晰的信息层级**：关键行动（预约、紧急联系）通过色彩对比和尺寸差异突出显示。红色仅用于紧急场景，避免视觉噪音。

**可访问性优先**：高对比度文本、大触控目标、清晰的表单标签，确保所有年龄段患者都能轻松使用。

### 视觉气质

**情感关键词**：
- *可信赖* — 蓝色体系 + 认证徽章 + 专业摄影，建立医疗信任
- *温暖关怀* — 圆角设计 + 柔和阴影 + 医生微笑照片，消除医疗冷感
- *高效专业* — 清晰网格 + 充足留白 + 结构化信息，传递组织有序感

**此设计不是什么**：
- 不是冷冰冰的医院官网——有温度、有人情味
- 不是花哨的营销页面——克制、专业、以功能为导向
- 不是深色科技风——明亮、干净、医疗白底

### 此风格的 DNA

#### 1. 双行动按钮体系
Hero 区域始终并排展示两个按钮：实心蓝色主按钮（Schedule Appointment）+ 白色描边次按钮（View Services），形成清晰的行动优先级。

#### 2. 浮动徽章卡片
图片上叠加白色圆角卡片（Board Certified / Open 7 Days），带柔和阴影，打破图片边界增加层次感。

#### 3. 统计数据展示
Hero 底部三列大数字统计（25+ / 50K+ / 98%），蓝色数字 + 灰色标签，用数据建立信任。

#### 4. 认证徽章行
页脚上方的认证徽章（JCAHO / HIPAA / ADA），绿色勾选图标 + 灰色文字，强化合规可信形象。

#### 5. 红色紧急 CTA
导航栏右侧红色 "Emergency" 按钮（#EF4444），与蓝色体系形成对比，仅用于紧急场景。

## "大胆要素"（签名元素）

1. **双 CTA 按钮并排**：Hero 区域始终展示两个并排按钮（实心 + 描边），形成清晰的行动优先级，避免单一 CTA 的压迫感。

2. **浮动信息卡片**：在图片上叠加白色圆角卡片（如 "Board Certified"、"Open 7 Days"），打破图片边界，增加视觉层次和信息密度。

3. **红色紧急按钮**：导航栏右侧独立的红色 "Emergency" 按钮，与蓝色体系形成强烈对比，仅用于紧急场景，建立视觉 urgency。

4. **统计数据信任行**：Hero 底部三列大数字统计（25+ / 50K+ / 98%），用具体数据建立专业信任，蓝色数字 + 灰色标签的清晰对比。

5. **认证徽章行**：页脚上方的 JCAHO / HIPAA / ADA 认证徽章，绿色勾选图标 + 灰色文字，强化合规可信形象。

6. **深色页脚对比**：深海军蓝（#1E3A5F）页脚与明亮页面主体形成强烈对比，包含 24/7 紧急电话红色卡片，信息丰富但不杂乱。

## 效果与动画

**运动哲学**：克制、专业、平滑。所有动画服务于功能反馈，不追求炫技。

**过渡默认**：
- 标准：`all 0.2s cubic-bezier(0.4, 0, 0.2, 1)`
- 入场：元素从下方淡入（translateY(20px) → 0, opacity 0 → 1），持续 0.5s
- 悬停：卡片上浮 2px，阴影加深，持续 0.2s

**持续动画**（如有）：
- 无持续动画，保持专业克制

**关键帧动画**：
```css
@keyframes fadeInUp {
  from {
    opacity: 0;
    transform: translateY(20px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}
```

## 响应式策略

**断点哲学**：移动端优先，逐步增强。1024px 和 768px 两档断点。

- **Hero**：桌面端 50/50 分栏 → 平板端文本上图片下 → 移动端单列堆叠
- **Services/Doctors**：桌面端 3-4 列 → 平板端 2 列 → 移动端 1 列
- **Footer**：桌面端 4 列 → 平板端 2 列 → 移动端单列
- **导航**：桌面端完整菜单 → 移动端汉堡菜单

**关键适配**：
- 标题尺寸：桌面 48-56px → 平板 36-42px → 移动 28-32px
- 间距缩减：桌面 80-96px → 平板 60px → 移动 40px
- 按钮全宽：移动端按钮拉伸至全宽

## 可访问性与最佳实践

**色彩对比**：蓝色 #0066CC 在白色背景上对比度 4.6:1（符合 AA 标准），深灰 #0F172A 文字对比度 15:1（符合 AAA 标准）。

**聚焦状态**：输入框和按钮聚焦时显示 2px 蓝色轮廓（outline: 2px solid #0066CC, outline-offset: 2px）。

**触控目标**：所有按钮和链接最小 44x44px，移动端按钮全宽。

**运动**：尊重 `prefers-reduced-motion`，禁用入场动画和悬停过渡。
