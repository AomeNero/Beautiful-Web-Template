## 布局创意 (Layout Ideas)

### Hero

两栏布局：左侧为文案区（徽章标签 + 大标题 + 描述 + 双按钮 + 统计数据），右侧为圆角大图。图片右上角和左下角各有一个漂浮徽章（评分/有机认证），形成视觉锚点。背景为极浅粉色。

### About

两栏布局反转：左侧为圆角大图，右侧为文案区（粉色小标签 + 标题 + 描述 + 四宫格特性图标）。特性图标使用粉色圆形背景 + 简约线条图标。

### Testimonials

居中布局：粉色小标签 + 标题（部分文字粉色），下方为三列卡片网格。卡片白底、圆角、柔和阴影，包含头像、星级评分、评价文本和客户姓名。

### Booking Form

居中单栏表单：浅粉背景卡片容器，两列网格排列输入框（姓名/电话/服务选择/日期），全宽文本域，底部全宽金色胶囊按钮。

### Footer

浅粉背景，四栏布局：左侧品牌区（Logo + 标语 + 社交图标），右侧三栏链接（Services / Company / Support）。底部分隔线 + 版权信息 + 隐私/条款链接。

## 完整提示词 (Full Prompt)

# 设计风格：Beauty-Spa

## 设计哲学

### 核心原则

此设计追求宁静、疗愈与优雅的平衡。以极浅粉色为画布，金色为行动引导，衬线字体传递经典美感，无衬线字体保证可读性。拒绝任何尖锐、紧张或高对比的视觉元素，一切服务于"放松"这一核心情感。

### 视觉气质

柔和、温暖、专业、可信赖。如同走进一家高端水疗中心——光线柔和、气味芬芳、触感细腻。

**情感关键词**：
- *宁静* — 极浅粉色背景与大量留白营造呼吸感
- *疗愈* — 圆角、柔和阴影、有机形态传递安全感
- *精致* — Playfair Display 衬线标题与金色点缀提升品质感

**此设计不是什么**：
- 不是高对比的极简主义——它拥抱柔和色调与温暖质感
- 不是冷峻的科技风——它拒绝冷蓝色调与锐利几何
- 不是张扬的奢华——金色仅作点缀，不喧宾夺主

### 此风格的 DNA

#### 1. 浅粉画布
全局使用 #FFF5F5 极浅粉色作为主背景，替代纯白，营造温暖疗愈氛围。

#### 2. 金色行动点
所有 CTA 按钮使用 #FFD700 金色，圆角胶囊形态，在柔和背景中形成唯一视觉焦点。

#### 3. 衬线标题 + 无衬线正文
Playfair Display 用于所有标题（优雅、经典），DM Sans 用于正文（现代、可读）。

#### 4. 漂浮徽章
图片角落的浮动信息卡片（评分、认证），白色背景 + 柔和阴影，增加层次感与信任感。

#### 5. 粉色点缀文字
标题中的关键词使用 #FFB6C1 浅粉色，形成视觉节奏而不破坏整体柔和感。

## 设计 Token 系统（DNA）

### 色彩策略

**色彩聚焦**：以极浅粉色为基底，金色为行动引导，深灰为文字主体，浅粉为装饰点缀。整体色调温暖柔和，避免任何冷色或高饱和色。

| Token | 值 | 用法与上下文 |
|:------|:------|:----------------|
| `background` | `#FFF5F5` | 页面主背景、Footer 背景 |
| `surface` | `#FFFFFF` | 卡片、表单容器、导航栏 |
| `foreground` | `#0F172A` | 主标题、Logo 文字 |
| `foreground-secondary` | `#2D2D2D` | 正文标题、卡片标题 |
| `muted` | `#6B7280` | 描述文字、辅助信息 |
| `accent` | `#FFD700` | CTA 按钮、星级评分 |
| `accent-pink` | `#FFB6C1` | 标题点缀文字、标签背景、图标背景 |
| `accent-green` | `#90EE90` | 有机认证徽章图标 |
| `border` | `#E2E8F0` | 输入框边框、分隔线 |
| `border-soft` | `#F3E8E8` | 卡片边框、微妙分隔 |

**签名渐变**：
```css
background: linear-gradient(135deg, #FFF5F5 0%, #FFFFFF 100%);
```

### 字体系统

**字体配对**：
- **展示字体**：`Playfair Display` — 用于所有标题，传递优雅、经典、高端的水疗气质
- **UI/正文字体**：`DM Sans` — 用于正文、导航、按钮，现代几何无衬线，保证可读性

**字号阶梯与用法**：

| 元素 | 尺寸 | 字体 | 字重 | 字距 | 备注 |
|:--------|:-----|:-----|:-------|:---------|:------|
| Hero 标题 | 56px | Playfair Display | 700 | -0.02em | 关键词粉色点缀 |
| 区块标题 | 40px | Playfair Display | 700 | -0.01em | 部分文字粉色 |
| 卡片标题 | 20px | DM Sans | 600 | 0 | 深色 |
| 正文 | 16px | DM Sans | 400 | 0 | 灰色 #6B7280 |
| 标签 | 13px | DM Sans | 600 | 0.05em | 大写，粉色 |
| 导航链接 | 15px | DM Sans | 500 | 0 | 深灰 |
| 按钮文字 | 16px | DM Sans | 600 | 0 | 深色或白色 |
| 统计数据 | 32px | DM Sans | 700 | 0 | 深色数字 |

### 间距与布局

- **区块间距**：垂直内边距 80-100px，区块间充足呼吸空间
- **容器宽度**：max-width 1200px，居中布局
- **网格间隙**：卡片网格 gap 24-32px
- **非对称模式**：Hero 与 About 采用 1:1 两栏布局，图片与文案各占 50%

**常见间距值**：8px / 16px / 24px / 32px / 48px / 80px

### 边框、表面与阴影

**圆角策略**：
- 按钮：999px（完全胶囊形）
- 卡片：16px
- 图片：20px
- 输入框：12px
- 徽章：12px

**边框**：1px solid，颜色 #E2E8F0（输入框）或 #F3E8E8（卡片）

**阴影系统**：

| Token | 值 | 用法 |
|:------|:------|:------|
| `shadow-sm` | `0 2px 8px rgba(15, 23, 42, 0.06)` | 卡片、徽章 |
| `shadow-md` | `0 8px 24px rgba(15, 23, 42, 0.08)` | 漂浮徽章、表单容器 |
| `shadow-lg` | `0 16px 48px rgba(15, 23, 42, 0.12)` | Hero 图片、导航栏 |

**纹理与图案**：无纹理，纯色彩表面，保持干净柔和。

## 组件样式与交互

### 按钮

**主按钮（金色 CTA）**：
- 背景：#FFD700
- 文字：#0F172A（深色）
- 圆角：999px（胶囊形）
- 悬停：轻微上移 translateY(-2px)，阴影加深
- 激活：scale(0.98)

**次/描边按钮**：
- 背景：透明
- 边框：1.5px solid #FFB6C1（粉色）
- 文字：#0F172A
- 圆角：999px
- 悬停：背景变为极浅粉色 #FFF5F5

### 卡片
- 背景：#FFFFFF
- 边框：1px solid #F3E8E8
- 圆角：16px
- 阴影：shadow-sm
- 悬停：阴影加深至 shadow-md，轻微上移

### 输入框
- 背景：#FFFFFF
- 边框：1px solid #E2E8F0
- 圆角：12px
- 聚焦：边框变为 #FFB6C1，无外发光
- 占位符：#9CA3AF

### 导航
- 背景：#FFFFFF（固定顶部，柔和阴影）
- Logo：Playfair Display，"Serenity" 深色 + "Spa" 粉色
- 链接：DM Sans 500，深灰色，悬停变深
- CTA 按钮：金色胶囊，与页面 CTA 一致

### 徽章/标签
- 形状：圆角胶囊或圆形
- 背景：#FFB6C1（粉色）或 #FFFFFF（白色漂浮）
- 字体：DM Sans 600，13px，大写
- 用法：区块标签（ABOUT US、TESTIMONIALS）、评分徽章、认证徽章

## "大胆要素"（签名元素）

1. **漂浮徽章**：图片角落的白色浮动信息卡片（4.9 评分、100% Organic），带柔和阴影，打破图片边界，增加层次与信任感。
2. **粉色关键词点缀**：标题中特定词汇（"Renew"、"Wellness"、"Clients Say"）使用 #FFB6C1 粉色，在深色衬线标题中形成优雅节奏。
3. **金色唯一焦点**：整个页面仅 CTA 按钮使用 #FFD700 金色，在浅粉画布中形成唯一强视觉引导，克制而有效。
4. **双色调 Logo**："Serenity" 深色衬线 + "Spa" 粉色衬线，同一字体内实现品牌双色表达。

## 效果与动画

**运动哲学**：轻柔、舒缓，如同水疗体验本身。所有动画缓慢而优雅，拒绝急促或弹跳效果。

**过渡默认**：
- 标准：`all 0.3s ease`
- 入场：`opacity 0.6s ease, transform 0.6s ease`（从下方 20px 淡入）
- 悬停：`transform 0.3s ease, box-shadow 0.3s ease`

**持续动画**：
- 漂浮徽章：`float 3s ease-in-out infinite`（轻微上下浮动）

**关键帧动画**：
```css
@keyframes float {
  0%, 100% { transform: translateY(0); }
  50% { transform: translateY(-8px); }
}

@keyframes fadeInUp {
  from { opacity: 0; transform: translateY(20px); }
  to { opacity: 1; transform: translateY(0); }
}
```

## 响应式策略

**断点哲学**：平板（1024px）开始简化两栏为单栏，手机（768px）全面堆叠，保持充足间距。

- **Hero**：桌面两栏 → 平板/手机单栏，图片移至文案下方
- **About**：桌面两栏 → 平板/手机单栏，图片在上文案在下
- **Testimonials**：三列 → 两列 → 单列
- **Footer**：四栏 → 两栏 → 单栏

**关键适配**：
- 标题尺寸：56px → 40px → 32px
- 区块间距：80px → 60px → 40px
- 漂浮徽章：桌面显示 → 手机隐藏

---

## 可访问性与最佳实践

**色彩对比**：深色文字 #0F172A 在 #FFF5F5 背景上对比度 > 15:1，满足 AAA 标准。金色按钮文字使用深色确保可读性。

**聚焦状态**：输入框聚焦时边框变为 #FFB6C1，按钮聚焦时显示 2px 粉色外环。

**触控目标**：所有按钮最小高度 48px，导航链接间距充足。

**运动**：`prefers-reduced-motion: reduce` 时禁用所有动画与过渡，漂浮徽章停止浮动。

## 实现说明

- **组件结构**：单文件 HTML，内联 CSS + JS，零构建依赖
- **CSS 自定义属性**：所有颜色、间距、阴影、圆角均定义为 :root 变量，便于主题化
- **字体加载**：Google Fonts CDN 加载 Playfair Display + DM Sans
- **动画库**：原生 CSS 动画 + IntersectionObserver 入场动画，无需第三方库
