## 布局创意 (Layout Ideas)

### Header

固定顶部导航栏，白色背景配底部细边框。左侧品牌 Logo（蓝绿渐变圆角方块 + 视频图标 + "MediConnect" 文字），中间导航链接（Features / Find Doctors / Health Tracking / Download App），右侧 Sign In 文字链接 + 蓝色圆角 CTA 按钮。

### Hero

非对称双列布局。左侧：信任徽章（浅蓝胶囊形，带勾选图标）→ 大标题（"Healthcare at Your Fingertips"，"Fingertips" 用蓝绿渐变文字）→ 描述段落 → 双按钮（主按钮蓝色填充 + 次按钮描边）→ 三列统计数据（500K+ / 2,000+ / 4.9）。右侧：视频通话场景图（医生与患者），底部浮动信息卡片（医生头像 + 姓名 + 职称 + 绿色 Live 徽章），底部控制栏（麦克风/摄像头/电话/聊天图标按钮）。

### Features

区块标题居中，描述文字居中。功能卡片网格布局，每张卡片含图标（彩色圆形背景）、标题、描述文字。

### Find Doctors

区块标题 + 描述居中。分类筛选胶囊按钮组（All / General / Cardiology / Dermatology / Psychiatry / Pediatrics），选中态为蓝色填充。医生卡片 4 列网格：顶部照片 + "Available Now" 绿色徽章 → 姓名 → 专科（蓝色文字）→ 评分（黄色星星 + 数字 + 评论数）→ 下次可预约时间 → 蓝色 "Book Consultation" 按钮。底部 "View All Doctors" 描边按钮。

### Health Tracking

功能展示区块，左侧文字 + 右侧手机模型展示。

### Download App

双列布局，左侧文字 + App Store / Google Play 下载按钮 + 评分与下载量统计，右侧手机模型展示。

### Footer

深海军蓝背景（#1A2744 附近），五列布局：品牌区（Logo + 标语 + 社交图标）+ Product / Company / Resources / Legal 四列链接。底部版权行 + HIPAA Compliant / SOC 2 Certified 认证徽章。

# 设计风格：Telemedicine

## 设计哲学

### 核心原则

专业可信赖的医疗科技美学。以蓝绿渐变为核心视觉语言，传递健康、科技与信任的三重信号。界面干净明亮，信息层级清晰，让患者感到安心，让医生感到高效。拒绝冷冰冰的医院感，追求温暖而专业的数字医疗体验。

### 视觉气质

明亮、洁净、充满希望的医疗科技氛围。蓝绿渐变如生命脉动，白色画布如无菌室的纯净，圆角卡片如温和的关怀。

**情感关键词**：
- *可信赖* — 蓝色系传递专业与安全感，统计数据与认证徽章强化信任
- *温暖* — 圆角设计、柔和阴影、真人照片消解医疗距离感
- *高效* — 清晰的信息架构、一键预约、实时状态指示

**此设计不是什么**：
- 不是冷峻的医院信息系统，没有冰冷的表格与灰暗色调
- 不是花哨的消费级应用，没有过度装饰与娱乐化元素
- 不是严肃的学术医疗门户，没有密集的文字与复杂的导航

### 此风格的 DNA

#### 1. 蓝绿渐变签名
从 #4F8CFF（科技蓝）到 #00C9A7（生命绿）的对角线渐变，贯穿 Logo、主按钮、标题强调文字与装饰元素，是品牌的视觉心跳。

#### 2. 圆角卡片体系
所有交互卡片使用 12-16px 圆角，配合柔和的蓝色投影（rgba(79, 140, 255, 0.15) 0px 20px 60px），营造浮动而友好的视觉层次。

#### 3. 实时状态徽章
绿色 "Available Now" 胶囊徽章与红色 "Live" 指示器，用色彩编码传递即时可用性信息，增强平台的实时感与紧迫感。

#### 4. 真人照片融合
医生卡片使用真实人物照片而非插画，配合视频通话场景的 Hero 图，建立人与人之间的信任连接。

#### 5. 统计数字信任体系
Hero 区域的 500K+ / 2,000+ / 4.9 三列数据，用超大字号展示关键指标，以数据驱动信任建立。

#### 6. 深蓝页脚锚定
与明亮主体形成强烈对比的深海军蓝页脚，承载认证徽章（HIPAA / SOC 2），在视觉上锚定专业性与合规性。

## 设计 Token 系统（DNA）

### 色彩策略

**色彩聚焦**：以蓝绿渐变为核心，白色为画布，深蓝为锚点。蓝色代表科技与信任，绿色代表生命与健康，深蓝代表专业与稳重。辅助色（紫/粉/橙/青）用于功能分类与数据可视化点缀。

| Token | 值 | 用法与上下文 |
|:------|:------|:----------------|
| `background` | `#FFFFFF` | 主背景色，纯白画布 |
| `background-soft` | `#F8FAFC` | 次级背景，区块交替 |
| `background-accent` | `#EEF4FF` | 浅蓝高亮背景，徽章/选中态 |
| `foreground` | `#0F172A` | 主文字色，深石板 |
| `foreground-muted` | `#64748B` | 次要文字，描述与标签 |
| `accent` | `#4F8CFF` | 主强调色，科技蓝，按钮/链接/图标 |
| `accent-secondary` | `#00C9A7` | 次强调色，生命绿，徽章/状态 |
| `accent-gradient` | `linear-gradient(135deg, #4F8CFF 0%, #00C9A7 100%)` | 品牌渐变，Logo/标题强调/主按钮 |
| `border` | `#E2E8F0` | 默认边框色 |
| `border-strong` | `#1E293B` | 强调边框 |
| `footer-bg` | `#1A2744` | 页脚深海军蓝背景 |

| `success` | `#00C9A7` | 成功/可用状态 |
| `warning` | `#FF9F43` | 警告/注意 |

### 字体系统

**字体配对**：
- **展示字体**：`Space Grotesk` — 几何感无衬线，用于 Hero 标题与区块标题，现代科技感
- **UI/正文字体**：`DM Sans` — 圆润友好的无衬线，用于正文、卡片内容与导航，清晰易读

**字号阶梯与用法**：

| 元素 | 尺寸 | 字体 | 字重 | 字距 | 备注 |
|:--------|:-----|:-----|:-------|:---------|:------|
| Hero 标题 | 56-64px | Space Grotesk | 700 | -0.02em | 渐变文字强调关键词 |
| 区块标题 | 36-40px | Space Grotesk | 700 | -0.01em | 居中对齐 |
| 卡片标题 | 18-20px | DM Sans | 600 | 0 | 医生姓名/功能名 |
| 正文 | 16px | DM Sans | 400 | 0 | 描述文字 |
| 标签 | 13-14px | DM Sans | 500 | 0.01em | 徽章/分类/元信息 |
| 统计数字 | 36-42px | Space Grotesk | 700 | -0.02em | Hero 统计数据 |
| 导航链接 | 15px | DM Sans | 500 | 0 | 导航栏文字 |

### 间距与布局

- **区块间距**：垂直内边距 80-96px，区块间呼吸感充足
- **容器宽度**：max-width 1200-1280px，居中布局
- **网格间隙**：卡片网格 gap 24-32px
- **非对称模式**：Hero 区左文右图，比例约 1:1

**常见间距值**：8px / 12px / 16px / 20px / 24px / 28px / 32px / 48px / 64px / 80px / 96px

### 边框、表面与阴影

**圆角策略**：
- 按钮/徽章：50px（胶囊形）
- 卡片：16-20px
- 图片/头像：12-14px
- Logo 图标：12px

**边框**：1px solid #E2E8F0 为主，2px solid 用于选中态/强调

**阴影系统**：

| Token | 值 | 用法 |
|:------|:------|:------|
| `shadow-sm` | `0 4px 14px rgba(79, 140, 255, 0.3)` | 按钮/小元素 |
| `shadow-md` | `0 20px 60px rgba(79, 140, 255, 0.15)` | 卡片/浮动元素 |
| `shadow-lg` | `0 10px 15px rgba(0,0,0,0.1), 0 4px 6px rgba(0,0,0,0.1)` | 手机模型/大元素 |
| `shadow-neumorphic` | `8px 8px 20px rgba(148,163,184,0.15), -8px -8px 20px rgba(255,255,255,0.8)` | 新拟态效果 |

**纹理与图案**：Hero 区域有微妙的蓝绿色径向渐变光晕作为背景装饰。

## "大胆要素"（签名元素）

1. **蓝绿双色渐变品牌系统**：从 #4F8CFF 到 #00C9A7 的渐变不仅用于装饰，更贯穿 Logo、标题强调、按钮、图标背景，形成统一的品牌心跳。
2. **视频通话场景 Hero**：以真实的远程医疗视频通话界面作为 Hero 视觉，包含医生头像、Live 徽章、底部控制栏，直接展示产品核心功能。
3. **实时可用性指示**：医生卡片上的绿色 "Available Now" 徽章与预约时间，将平台的核心价值（即时连接）可视化。
4. **深蓝页脚认证体系**：与明亮主体形成戏剧性对比的深海军蓝页脚，承载 HIPAA / SOC 2 认证徽章，用视觉重量锚定专业信任。
5. **统计数据信任三柱**：500K+ 用户 / 2,000+ 医生 / 4.9 评分，以超大字号在 Hero 区直接展示，用数据说话。

## 效果与动画

**运动哲学**：轻柔、专业、有目的性。动画服务于信息传达而非装饰，入场动画采用淡入上移，悬停采用微妙的位移与阴影变化。

**过渡默认**：
- 标准：all 0.3s cubic-bezier(0.4, 0, 0.2, 1)
- 入场：opacity 0→1 + translateY(20px→0)，持续 0.6s
- 悬停：transform translateY(-2px) + shadow 加深

**持续动画**（如有）：
- `gradient`：背景位置 0%→100%→0% 循环，用于渐变文字/背景
- `float`：translateY(0→-20px→0)，用于浮动装饰元素
- `glow`：box-shadow 强度脉动，用于 CTA 按钮
- `pulse`：透明度 1→0.5→1，用于 Live 指示器

**关键帧动画**：
```css
@keyframes gradient {
  0%, 100% { background-position: 0% center; }
  50% { background-position: 100% center; }
}
@keyframes float {
  0%, 100% { transform: translateY(0px); }
  50% { transform: translateY(-20px); }
}
@keyframes glow {
  0% { box-shadow: 0 0 20px rgba(37, 99, 235, 0.3); }
  100% { box-shadow: 0 0 40px rgba(37, 99, 235, 0.6); }
}
```

## 响应式策略

**断点哲学**：移动优先，内容优先。小屏幕堆叠为单列，中等屏幕恢复网格，大屏幕展示完整布局。

- **Hero**：移动端单列堆叠（文字上/图下），桌面端双列并排
- **医生卡片**：移动端 1 列 → 平板 2 列 → 桌面 4 列
- **功能卡片**：移动端 1 列 → 平板 2 列 → 桌面 3 列
- **Footer**：移动端单列堆叠 → 桌面端五列并排

**关键适配**：
- Hero 标题从 56px 缩至 36px
- 区块间距从 96px 缩至 64px
- 统计数据从三列并排变为水平滚动或堆叠
- 装饰性渐变光晕在小屏幕减弱或隐藏

## 可访问性与最佳实践

**色彩对比**：主文字 #0F172A 在白色背景上对比度 > 15:1，符合 AAA 标准。蓝色 #4F8CFF 在白色上约 3.5:1，用于大文字/图标时符合 AA。

**聚焦状态**：输入框与按钮聚焦时显示蓝色外环（outline: 2px solid #4F8CFF, outline-offset: 2px）。

**触控目标**：所有可交互元素最小 44x44px，按钮内边距充足。

**运动**：prefers-reduced-motion 时禁用所有动画与过渡，入场动画改为直接显示。

## 实现说明

- **组件结构**：纯 HTML + CSS，零构建依赖，单文件组件库
- **CSS 自定义属性**：所有设计 Token 定义在 :root 中，支持主题化
- **字体加载**：Google Fonts CDN 加载 Space Grotesk (400-700) + DM Sans (400-700)
- **动画库**：原生 CSS 动画 + IntersectionObserver 入场动画，无外部依赖
- **图片**：使用在线 AI 生成图片 URL 或占位符
