## 布局创意 (Layout Ideas)

### Hero

居中单列布局。顶部"AI-POWERED ART GENERATION"胶囊标签（品红半透明背景+青色文字），超大标题"Create Infinite Art Possibilities"其中"Infinite"使用品红→青→绿渐变文字，副标题描述 AI 艺术生成，双 CTA 按钮（渐变实心主按钮 + 描边次按钮），下方为内嵌式 AI 艺术生成器预览卡片。

### Generator Preview

Hero 区下方直接嵌入生成器界面预览。深色卡片带边框，顶部含文本输入框+生成按钮，中部为 2x2 艺术作品网格展示，底部显示生成时间和 AI 引擎标识。

### Style Gallery

"CURATED COLLECTION"标签区，"Style Gallery"标题其中"Gallery"使用渐变文字。风格筛选标签栏（All、Abstract、Geometric、Surreal 等），不规则网格艺术作品展示（含大尺寸特色作品），底部"View All Artworks"按钮。

### Creator Tools

"PRO FEATURES"标签区，"Creator Tools"标题其中"Tools"使用渐变文字。三列特性卡片网格，每张卡片带彩色图标容器（品红/青/绿）、标题和描述文字。深色背景区块，卡片带悬停辉光效果。

### Stats

四列数据统计网格，数字使用品红→青渐变文字（10M+、50K+、15s、99.9%），下方为灰色说明文字。上下带边框分隔线。

### NFT Minting

"From Creation to Collection"标题区，"Collection"使用渐变文字。左侧为四步骤说明（编号圆形徽章+标题+描述），右侧为 NFT 铸造预览卡片（ artworks 图片+区块链选择按钮+Gas 费用+铸造按钮）。

### Footer

深色背景，多列链接布局（Product、Resources、Company），左侧 Logo+描述+社交图标，底部版权信息和法律链接。

## 完整提示词 (Full Prompt)

# 设计风格：Generative-Art-Platform / 霓虹暗色生成艺术

## 设计哲学

**核心原则**：将 AI 艺术创作体验置于设计中心，以深色画布为舞台，让霓虹色彩自然绽放。这种风格融合了赛博朋克的未来感与当代艺术的实验性——**纯黑背景**作为无限画布，**品红/青/绿三色渐变**作为创意灵魂，**生成式艺术**作为核心隐喻。每个元素都应传递"创新、前沿、无限可能"的感受。

**气质**：未来感、创新、艺术性、科技感、实验性、大胆、沉浸式。

**Generative-Art-Platform 的承诺**：这不是一个普通的工具落地页——它是一个创意实验室的入口。生成器界面本身就是 Hero 视觉，用户无需滚动即可理解产品核心价值。霓虹渐变不只是装饰，而是"AI 创造力"的视觉编码。

## 设计 Token 系统（DNA）

### 色彩系统（霓虹三色）

**基础色**：
- **background**：`#0A0A0A`（纯黑）— 页面底色，深邃无限
- **backgroundAlt**：`#111111`（近黑）— 卡片、内容区背景
- **foreground**：`#FFFFFF`（纯白）— 主要文字，高对比度
- **muted**：`#888888`（中灰）— 次要文字、描述
- **border**：`#333333`（深灰）— 边框与分隔符
- **borderLight**：`rgba(255, 255, 255, 0.1)`（淡白）— 轻量分隔

**品牌色（霓虹三色）**：
- **primary**：`#FF00FF`（品红）— 主品牌色，按钮、高亮
- **primaryHover**：`#E600E6`（品红深）— 悬停状态
- **secondary**：`#00FFFF`（青色）— 辅助色，标签、强调
- **secondaryHover**：`#00E6E6`（青色深）— 悬停状态
- **accent**：`#00FF00`（绿色）— 点缀色，成功、特殊强调
- **primaryGradient**：`linear-gradient(135deg, #FF00FF 0%, #00FFFF 100%)` — 双色渐变
- **gradientText**：`linear-gradient(135deg, #FF00FF 0%, #00FFFF 50%, #00FF00 100%)` — 三色渐变文字

**功能色**：
- **success**：`#00FF00`（霓虹绿）— 在线状态、成功指示
- **warning**：`#FF9900`（琥珀）— 警告、注意
- **danger**：`#FF4A00`（橙红）— 错误、危险

**用色规则**：
1. **对比度**：白色文字对黑色背景保持 21:1，次要文字最低 4.5:1
2. **分层策略**：深色卡片叠加于纯黑底色之上，营造微妙深度
3. **霓虹点缀**：品红/青/绿仅用于关键交互元素和视觉焦点
4. **渐变应用**：标题文字、主按钮、图标背景使用渐变增强视觉冲击

### 字体系统

**字体族**：
- **heading**：`'Space Grotesk', sans-serif` — 几何感标题字体，现代科技气质
- **body**：`'DM Sans', sans-serif` — 清晰易读正文字体
- **accent**：`'Manrope', sans-serif` — 辅助字体，用于特殊场景

**字重**：
- **light**：300 — 大标题装饰性使用
- **regular**：400 — 正文默认
- **medium**：500 — 次要文字、标签
- **semibold**：600 — 小标题、按钮
- **bold**：700 — 主标题、重要数据

**字号**：
- **hero**：`clamp(3rem, 8vw, 5.5rem)` — 超大标题，响应式
- **h1**：`clamp(2.5rem, 5vw, 3.5rem)` — 区块标题
- **h2**：`2rem` — 次级标题
- **h3**：`1.25rem` — 卡片标题
- **body**：`1rem` — 正文
- **small**：`0.9rem` — 次要文字
- **caption**：`0.85rem` — 标签、说明

### 圆角系统

- **sm**：`8px` — 小按钮、图标容器
- **base**：`12px` — 标准卡片、输入框
- **lg**：`16px` — 大卡片、艺术作品
- **xl**：`24px` — 特殊卡片、预览区
- **pill**：`999px` — 胶囊标签、标签按钮

### 阴影系统

- **sm**：`0 2px 4px rgba(0, 0, 0, 0.3)` — 轻微浮起
- **base**：`0 4px 12px rgba(0, 0, 0, 0.4)` — 标准卡片
- **lg**：`0 8px 24px rgba(0, 0, 0, 0.5)` — 悬浮卡片
- **glow**：`0 0 40px rgba(255, 0, 255, 0.3)` — 品红辉光
- **glowCyan**：`0 0 40px rgba(0, 255, 255, 0.3)` — 青色辉光

### 间距系统

- **xs**：`4px` — 微小间距
- **sm**：`8px` — 紧凑间距
- **base**：`16px` — 标准间距
- **md**：`24px` — 中等间距
- **lg**：`32px` — 大间距
- **xl**：`48px` — 区块内间距
- **2xl**：`64px` — 区块间距
- **3xl**：`96px` — 大区块间距

### 动画与过渡

- **fast**：`150ms ease-out` — 快速交互反馈
- **base**：`200ms ease-out` — 标准过渡
- **slow**：`300ms ease-out` — 复杂动画

**关键动画**：
- **gradient**：背景位置移动，创造流动渐变效果
- **float**：上下浮动，用于装饰元素
- **glow**：辉光强度变化，用于悬停状态
- **shimmer**：光泽扫过，用于加载状态

## 无障碍规范

### 对比度

- **主要文字**：白色 `#FFFFFF` 对黑色 `#0A0A0A` = 21:1 ✓
- **次要文字**：灰色 `#888888` 对黑色 `#0A0A0A` = 5.7:1 ✓
- **品牌色文字**：黑色 `#000000` 对渐变背景 = 需确保足够对比度

### 键盘导航

- 所有交互元素可通过 Tab 键访问
- 焦点状态清晰可见
- 按钮和链接有明确的激活状态

### 屏幕阅读器

- 语义化 HTML 标签（nav、section、footer）
- 图片有 alt 文本
- 按钮有明确的标签

## 性能优化

### 字体加载

- 使用 `preconnect` 预连接 Google Fonts
- 字体显示策略：`swap`
- 仅加载所需字重（300、400、500、600、700）

### 图片优化

- 使用 Unsplash CDN 图片
- 指定尺寸参数（w=400、w=800 等）
- 使用 `object-fit: cover` 确保裁剪

### CSS 优化

- 使用 CSS 变量统一管理设计 Token
- 避免重复样式定义
- 使用 `clamp()` 实现响应式字号
