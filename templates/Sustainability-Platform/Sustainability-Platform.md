## 完整提示词 (Full Prompt)

# 高保真 Sustainability Platform 设计系统

## 设计哲学

**核心概念：有机亲生物 + 极简主义**
此设计系统将可持续碳追踪平台包装为一个**自然、可信、专业**的数字体验。它融合有机亲生物美学（自然色调、有机形态、生态意象）与极简主义（大量留白、清晰层级、克制装饰），创造一种"呼吸感"界面——如同走进一片安静的森林。

**"亲生物"之别**：
不同于通用自然风格的"田园浪漫"感，此设计更强调**科学可信度**与**数据可视化**。绿色不是装饰性的，而是功能性的——用于强调关键数据、引导行动、标识成功状态。界面像一份精心排版的环保报告，而非旅游宣传册。

*   **材质性**：想象再生纸与磨砂玻璃的结合。背景是温暖的米白色（非纯白），卡片是干净的白色，带有柔和的投影。没有纹理噪点，但色彩本身带有自然的温度。
*   **光照**：均匀柔和的漫射光，没有强烈的方向性阴影。卡片使用微妙的弥散阴影（非硬偏移），营造轻轻浮起的质感。
*   **阴影架构**：
    - **卡片阴影**：`0 2px 8px rgba(0,0,0,0.06)` —— 极轻的弥散阴影
    - **悬浮阴影**：`0 8px 24px rgba(0,0,0,0.1)` —— 悬停时加深

**感官气质**：
*   **自然与有机**：森林绿主色调贯穿全局，从导航到 CTA 到数据可视化。暖白背景（#FAFAF5）模拟再生纸的质感，比纯白更温暖、更环保。
*   **科学与可信**：Fraunces 衬线字体用于标题和数据，传递权威感与编辑品质。DM Sans 正文清晰易读。数据可视化（圆环图、进度条）用精确的绿色渐变呈现。
*   **极简与呼吸**：大量留白，元素间距慷慨。没有多余的装饰线或分割线。每个区块有足够的呼吸空间。
*   **行动导向**：绿色 CTA 按钮使用胶囊形状（完全圆角），传递"开始行动"的积极信号。描边按钮用于次级操作。

**"亲生物"设计引擎**：
1.  **色彩编码（Color-coded）**：森林绿（#228B22）用于品牌、CTA、数据高亮；亮绿（#4CAF50）用于按钮和交互元素；深绿（#1B4332）用于 CTA 区块背景。
2.  **有机形态（Organic）**：所有按钮和徽章使用胶囊形状（pill）。卡片使用 16px 圆角。右上角的叶子装饰暗示自然主题。
3.  **数据可视化（Data-driven）**：碳足迹仪表盘使用圆环图 + 分类进度条，将抽象的环保数据转化为直观的视觉语言。
4.  **信任构建（Trust-building）**：B Corp 认证徽章、ISO 14064 合规标识、10,000+ 公司数据——每个信任信号都精心设计。

## 设计 Token 系统

### 色彩（"可持续森林"调色板）

**Background**：
*   **主画布**：`#FAFAF5`（暖米白）。模拟再生纸质感，比纯白更温暖自然。
*   **卡片背景**：`#FFFFFF`（纯白）。内容卡片使用纯白，在暖白画布上微微凸起。
*   **CTA 区块背景**：`#1B4332`（深森林绿）。全宽 CTA 区域使用深绿背景，白色文字形成强烈对比。

**Foreground**：
*   **文字（主要）**：`#0F172A`（深石板）。高对比度，确保可读性。
*   **文字（次要）**：`#52796F`（鼠尾草绿灰）。用于描述文字和次要信息，带有自然色调。
*   **文字（导航）**：`#52796F`（鼠尾草绿灰）。导航链接使用此色。

**点缀（自然绿色系）**：
*   **主色（森林绿）**：`#228B22`（森林绿）。用于品牌标识、标题强调、数据高亮、分类标签。
*   **次色（亮绿）**：`#4CAF50`（亮绿）。用于 CTA 按钮、进度条填充、徽章指示器。
*   **三色（深绿）**：`#1B4332`（深森林绿）。用于 CTA 区块背景、页脚深色区域。
*   **四色（天蓝）**：`#87CEEB`（天蓝）。用于 Supply Chain 进度条，区分能源类别。
*   **五色（琥珀）**：`#FFB300`（琥珀/橙黄）。用于 Renewable 徽章图标背景。
*   **边框**：`#D8E2DC`（浅鼠尾草）。卡片和输入框的边框色。

**渐变策略**：
*   **按钮**：纯色填充，不使用渐变。主按钮 `#4CAF50`，CTA 区块按钮同样。
*   **圆环图**：绿色渐变从 `#4CAF50` 到 `#228B22`，模拟自然生长感。
*   **进度条**：绿色 `#4CAF50` 填充，浅灰 `#E8E8E0` 轨道。
*   **文字高亮**：Hero 标题中 "Carbon" 用森林绿 `#228B22` 强调；CTA 标题中 "Positive Impact" 用亮绿 `#4CAF50` 强调。

### 字体

**字体选择**：
*   **标题**：**Fraunces**（Google Fonts，字重：400/500/600/700）。优雅的衬线字体，带有编辑品质感，完美匹配可持续品牌的专业形象。
*   **正文**：**DM Sans**（Google Fonts，字重：400/500/700）。几何、干净、高可读性的无衬线字体。

**层级**：
*   **Hero 标题**：`56-72px`，Fraunces 600-700，紧凑字距，行高 1.1。
*   **区块标题**：`36-44px`，Fraunces 600-700，行高 1.15。
*   **卡片标题**：`20-22px`，Fraunces 600。
*   **正文**：`16-17px`，DM Sans 400，行高 1.6-1.7。
*   **小文字**：`14-15px`，DM Sans 400-500。用于标签、元信息、导航。
*   **统计数字**：`48-56px`，Fraunces 700，绿色。

### 形状与圆角

**"有机圆角"规则**：
*   **大容器/卡片**：`16px` 圆角
*   **按钮**：`999px`（胶囊形状，完全圆角）
*   **徽章/胶囊**：`999px`（全圆角胶囊）
*   **导航栏**：无圆角（全宽）
*   **社交图标**：`50%`（圆形）

**关键规则**：
*   交互元素（按钮、徽章）使用胶囊形状，传递友好、可点击的感觉。
*   内容卡片使用适中的 16px 圆角，保持专业感。
*   仪表盘卡片使用 16px 圆角，与内容卡片一致。

### 阴影（柔和弥散）

**1. 卡片阴影**：
```css
box-shadow: 0 2px 8px rgba(0, 0, 0, 0.06);
```

**2. 卡片悬停阴影**：
```css
box-shadow: 0 8px 24px rgba(0, 0, 0, 0.1);
```

**3. 仪表盘卡片阴影**（稍重）：
```css
box-shadow: 0 4px 16px rgba(0, 0, 0, 0.08);
```

**4. 按钮**：无阴影，纯色填充，hover 时颜色加深。

## 动画系统

**1. 按钮悬停**：
```css
transition: all 0.2s ease;
hover: background-color 加深;
```

**2. 卡片悬停**：
```css
transition: all 0.3s ease;
hover: box-shadow 加深;
```

**3. 圆环图动画**：
```css
@keyframes draw-ring {
  from { stroke-dashoffset: 周长; }
  to { stroke-dashoffset: 目标值; }
}
```

**4. 进度条动画**：
```css
@keyframes fill-bar {
  from { width: 0; }
  to { width: 目标百分比; }
}
```

## 响应式策略

**断点**：
*   **桌面**：`>= 1024px` — 完整布局
*   **平板**：`768px - 1023px` — 两列网格，缩小间距
*   **移动**：`< 768px` — 单列堆叠，全宽按钮

**字体缩放**：
*   Hero 标题：`36px (移动) → 48px (平板) → 64px (桌面)`
*   区块标题：`28px (移动) → 36px (平板) → 44px (桌面)`
*   统计数字：`36px (移动) → 44px (平板) → 56px (桌面)`

**布局变换**：
*   **导航**：移动端隐藏非必要链接，显示汉堡菜单
*   **Hero**：移动端垂直堆叠，桌面端双栏
*   **统计**：移动端两列 → 桌面四列
*   **项目卡片**：移动端单列 → 平板两列 → 桌面三列
*   **Footer**：移动端单列堆叠 → 桌面五列

**组件调整**：
*   按钮：移动端全宽
*   卡片：移动端减少内边距
*   仪表盘：移动端简化，隐藏浮动徽章

## 该做与不该做

*   **该做** 使用暖白背景（#FAFAF5）而非纯白，营造自然质感。
*   **该做** 森林绿（#228B22）用于品牌、标题强调和数据高亮。
*   **该做** Fraunces 衬线用于所有标题和统计数字，DM Sans 用于正文。
*   **该做** 按钮使用胶囊形状（完全圆角）。
*   **该做** 卡片使用柔和弥散阴影（非硬偏移）。
*   **该做** 数据可视化使用绿色渐变圆环图和进度条。
*   **不该做** 使用硬偏移阴影（这是 Claymorphism 风格）。
*   **不该做** 使用渐变按钮——使用纯色填充。
*   **不该做** 文字颜色浅于 #52796F（可读性风险）。
*   **不该做** 使用锐角——所有交互元素至少 12px 圆角或胶囊形。
