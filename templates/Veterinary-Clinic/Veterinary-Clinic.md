## 完整提示词 (Full Prompt)

# 设计风格：Veterinary Clinic

## 设计哲学

### 核心原则

温暖而专业的医疗关怀美学。设计追求在医疗专业感与宠物主人的情感连接之间取得平衡——既传递兽医的专业可信度，又通过柔和的色彩、圆角元素和关怀性文案营造亲切感。拒绝冷冰冰的医疗机构感，也拒绝过度卡通化的宠物风格。

### 视觉气质

**情感关键词**：
- *温暖关怀* — 珊瑚橙与青绿的搭配传递温暖而不失专业的医疗氛围
- *可信赖* — 深蓝文字、整洁布局、信任指标卡片建立专业权威
- *亲近友好* — 大圆角、柔和阴影、宠物照片让访客感到被欢迎

**此设计不是什么**：
- 不是冷峻的医院风格（避免纯白+冷蓝的 sterile 感）
- 不是卡通宠物乐园（避免过度 playful 的插画风格）
- 不是高端奢侈品诊所（避免金色、深色奢华感）

### 此风格的 DNA

#### 1. 青绿 + 珊瑚双主色系统
青绿色 (#4A90A4) 作为主行动色贯穿导航、按钮、高亮文字；珊瑚橙 (#E76F51) 作为紧急/强调色用于 Emergency 按钮和 CTA 横幅。两色形成冷暖对比，既专业又有温度。

#### 2. 浮动信息卡片
Hero 区域的照片上叠加圆角白色信息卡（"Open 7 Days"、"15+ Years Experience"），带柔和阴影，创造层次感和信息密度。

#### 3. 信任指标微组件
小尺寸双列卡片展示认证（AVMA Certified）和评分（4.9 Rating），带图标和细边框，在 Hero 底部建立即时信任。

#### 4. 大圆角卡片系统
所有卡片、按钮、表单元素使用 12-16px 圆角，传递友好亲切的视觉语言。

#### 5. 深蓝文字层次
主标题使用深海军蓝 (#1E3A4C) 而非纯黑，配合青绿色高亮关键词，形成柔和而清晰的文字层次。

## "大胆要素"（签名元素）

1. **浮动信息卡叠加**：Hero 照片上叠加白色圆角信息卡（营业时间、经验年限），带阴影创造漂浮感，打破常规图文布局
2. **青绿 + 珊瑚冷暖双主色**：不依赖单一主色，而是用青绿（专业/冷静）和珊瑚（紧急/温暖）形成功能化色彩分工
3. **信任指标内嵌 Hero**：在 Hero 底部直接嵌入认证徽章和评分卡片，而非单独 Trust 区块，缩短信任建立路径
4. **深蓝替代纯黑**：所有文字使用 #1E3A4C 深海军蓝而非 #000000，配合浅蓝灰背景营造柔和医疗氛围
5. **Emergency 专属视觉通道**：珊瑚色 Emergency 按钮在导航中独立于主 CTA，形成紧急服务的专属视觉通道

## 效果与动画

**运动哲学**：轻柔、克制、专业。所有过渡使用 ease-out 缓动，持续时间 200-300ms，避免弹跳或夸张效果。

**过渡默认**：
- 标准：`all 0.2s ease-out`
- 入场：元素从下方 20px + opacity 0 滑入，持续 0.5s ease-out
- 悬停：按钮 translateY(-1px) + 阴影加深，卡片 translateY(-2px) + 阴影加深

**持续动画**（如有）：无持续动画，保持专业医疗感。

**关键帧动画**：
```css
@keyframes fadeInUp {
  from { opacity: 0; transform: translateY(20px); }
  to { opacity: 1; transform: translateY(0); }
}
```

## 响应式策略

**断点哲学**：移动端优先，内容堆叠，保持卡片可读性和按钮可触控性。

- **Hero**：桌面双栏 → 平板单栏（图在下） → 手机全宽堆叠，标题缩小至 36px
- **Team Grid**：4 列 → 2 列（768px） → 1 列（480px）
- **Footer**：4 列 → 2 列（768px） → 1 列（480px）
- **导航**：桌面水平链接 → 平板/手机汉堡菜单

**关键适配**：
- 标题尺寸：56px → 40px → 32px → 28px
- 区块间距：80px → 60px → 40px
- 浮动信息卡：桌面叠加照片 → 移动端移至照片下方

## 可访问性与最佳实践

**色彩对比**：主文字 #1E3A4C 在白色背景上对比度 > 7:1（AAA），青绿按钮文字白色对比度 > 4.5:1（AA）。珊瑚按钮文字白色对比度约 3.5:1，建议按钮文字加粗或增大字号。

**聚焦状态**：输入框聚焦时显示 3px rgba(74, 144, 164, 0.15) 外发光环，按钮聚焦显示 2px #4A90A4 outline。

**触控目标**：所有按钮最小 44x44px，导航链接 padding 充足。

**运动**：`@media (prefers-reduced-motion: reduce)` 时禁用所有 transition 和 animation，入场动画改为直接显示。

## 实现说明

- **组件结构**：纯 HTML + CSS，无框架依赖。使用 CSS 自定义属性实现主题化。
- **CSS 自定义属性**：所有色彩、间距、圆角、阴影均定义为 :root 变量，便于主题切换。
- **字体加载**：Google Fonts 加载 Space Grotesk (400, 500, 600, 700) 和 DM Sans (400, 500, 600, 700)。
- **动画库**：无需外部库，使用 CSS transition + IntersectionObserver 实现入场动画。
- **图标**：使用内联 SVG 图标，无需图标库。
