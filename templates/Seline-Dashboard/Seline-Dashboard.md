## 布局创意 (Layout Ideas)

### 侧边栏导航

- **整体布局**：固定左侧边栏，宽度约 240-260px
- **导航项**：垂直堆叠，图标 + 文字 + 快捷键提示
- **当前选中**：蓝色图标 + 加粗文字
- **底部区域**：Docs、Give feedback、Live chat、Sign out 链接

### 顶部工具栏

- **布局**：水平排列，右对齐
- **元素**：Live 指示器、Filter 按钮、日期范围选择器
- **样式**：白色背景，细微边框，圆角按钮

### 主内容区 - 空状态

- **布局**：居中卡片，包含插图 + 文字 + CTA 按钮
- **插图**：右侧人物插画，增加亲和力
- **CTA 按钮**：Install Seline（蓝色主按钮）+ Docs & Guides（次要按钮）

### 主内容区 - 数据卡片

- **布局**：网格布局，4 列统计卡片
- **卡片样式**：白色背景，细微边框，圆角
- **内容**：指标名称 + 数值 + 变化百分比
- **图表区域**：下方大卡片包含时间轴图表

### 数据表格区

- **布局**：全宽卡片，包含标签页切换
- **标签页**：Top / Entry / Exit 或 Channels / Referrers / Keywords
- **表格**：简洁行布局，无多余装饰

# 设计风格：Seline Dashboard

## 设计哲学

### 核心原则

**功能优先的极简主义**：此设计服务于数据分析场景，追求信息密度与可读性的平衡。每个像素都为数据服务，无装饰性冗余。

**清晰的视觉层级**：通过色彩、字重、间距建立明确的信息层级。重要数据突出显示，次要信息柔和呈现。

**友好的专业感**：通过插画、圆角、柔和色彩降低数据产品的冰冷感，同时保持专业可信度。

### 视觉气质

**情感关键词**：
- *清晰* — 数据呈现一目了然，无视觉噪音
- *友好* — 插画和圆角设计增加亲和力
- *专业* — 精准的间距和排版体现品质感

**此设计不是什么**：
- 不是花哨的营销页面 — 无渐变、无复杂动画、无装饰性背景
- 不是密集的企业报表 — 大量留白，呼吸感强
- 不是冷峻的数据工具 — 暖色调和插画增加温度

### 此风格的 DNA

#### 1. 左侧固定导航栏
白色/浅灰背景，图标 + 文字 + 快捷键的导航项组合。当前选中项用蓝色图标标识。底部放置辅助链接。

#### 2. 卡片式内容组织
所有数据模块都用白色卡片承载，细微边框（#E5E7EB），圆角 8px。卡片之间有清晰间距。

#### 3. 亮蓝主色系统
#3BA6F1 作为唯一强色彩，用于主按钮、选中状态、链接。克制使用，保持视觉焦点。

#### 4. Inter + Roobert 字体配对
正文使用 Inter（高可读性），标题使用 Roobert（几何感更强）。数字使用等宽字体确保对齐。

#### 5. 空状态插画
无数据时显示友好插画，降低用户焦虑，引导下一步操作。

## 设计 Token 系统（DNA）

### 色彩策略

**色彩聚焦**：白色基底 + 亮蓝点缀。整体低饱和度，仅关键操作使用蓝色。

| Token | 值 | 用法与上下文 |
|:------|:------|:----------------|
| `background` | `#FFFFFF` | 页面主背景，纯白 |
| `card` | `#FFFFFF` | 卡片背景，纯白 |
| `foreground` | `#0C0A09` | 主要文字，近黑 |
| `text-secondary` | `#78726D` | 次要文字，暖灰 |
| `text-muted` | `#A8A29E` | 辅助文字，浅灰 |

| `muted` | `#F5F5F4` | 次要背景，极浅暖灰 |

**字号阶梯与用法**：

## "大胆要素"（签名元素）

1. **左侧固定导航 + 快捷键提示**：每个导航项右侧显示键盘快捷键（D、V、F），提升专业用户效率。

2. **空状态插画引导**：无数据时不显示冷冰冰的"0"，而是用友好插画 + 明确 CTA 引导用户行动。

3. **Live 实时指示器**：顶部工具栏的 Live 按钮，带脉冲动画，传达实时数据感。

4. **数值变化箭头**：每个指标旁显示变化趋势箭头和百分比，即使为 0% 也保持信息完整性。

5. **标签页切换器**：数据表格上方的分段控制器（Top/Entry/Exit），背景 `#F5F5F4`，选中项白色。

6. **底部 AI 助手入口**："Ask Seline..." 输入框，暗示 AI 功能，增加产品现代感。

## 效果与动画

**运动哲学**：克制、快速、功能性。动画仅用于状态反馈和数据更新。

**过渡默认**：
- 标准：`all 0.15s cubic-bezier(0.4, 0, 0.2, 1)`
- 悬停：颜色、背景色 150ms 过渡
- 聚焦：边框和阴影快速切换

**持续动画**：
- Live 指示器：脉冲动画，透明度 0.5-1 循环
- 数据加载：骨架屏或 spinner

**关键帧动画**：
```css
@keyframes pulse {
  50% { opacity: 0.5; }
}

@keyframes spin {
  100% { transform: rotate(360deg); }
}
```

## 响应式策略

**断点哲学**：桌面优先，移动端侧边栏可折叠。

- **侧边栏**：桌面端固定显示，移动端可折叠为汉堡菜单
- **数据卡片**：桌面端 4 列，平板 2 列，移动端 1 列
- **图表**：移动端简化或隐藏细节

**关键适配**：
- 侧边栏宽度：桌面端 240px，移动端隐藏
- 卡片网格：4 列 → 2 列 → 1 列
- 字体尺寸：标题 24px → 20px，数值 28px → 24px

## 可访问性与最佳实践

**色彩对比**：
- 主要文字 #0C0A09 on #FFFFFF：对比度 > 15:1（AAA）
- 次要文字 #78726D on #FFFFFF：对比度约 4.6:1（AA）
- 主按钮文字 #FFFFFF on #3BA6F1：对比度约 3.5:1（建议加粗文字）

**聚焦状态**：
- 输入框聚焦：2px 蓝色外环
- 按钮聚焦：类似外环或边框变色
- 导航项聚焦：背景高亮

**触控目标**：
- 按钮高度：36-40px（接近 44px 建议）
- 导航项高度：36-40px

**运动**：
- 所有动画 150ms，快速不拖沓
- 支持 `prefers-reduced-motion`：禁用脉冲动画，保留必要过渡

## 实现说明

- **组件结构**：React/Vue 组件库，侧边栏 + 主内容区布局
- **CSS 自定义属性**：使用 `:root` 定义所有 Token
- **字体加载**：
  ```html
  <link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&display=swap" rel="stylesheet">
  ```
  Roobert 需自行托管
- **图表库**：推荐 Recharts、Chart.js 或 ECharts
- **图标**：Lucide Icons 或 Heroicons
