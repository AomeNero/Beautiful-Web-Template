## 布局创意 (Layout Ideas)

### Hero

双栏网格布局（1:1），左侧为文案区（徽章 + 大标题 + 描述 + 双按钮 + 统计数据行），右侧为深色代码块展示。标题中 "internet" 一词使用靛蓝到青色的渐变文字效果。统计数据以三列等宽排列，数字加粗突出。

### Features / Products

浅灰蓝交替背景区块，三列卡片网格（gap: 32px），每张卡片包含图标容器（48×48 圆角方块，淡靛蓝背景）、标题、描述文字。卡片白色背景 + 细边框，悬停时出现柔和阴影。

### Pricing

三列定价卡片网格，中间卡片为"Popular"推荐款，顶部悬浮紫色徽章，边框高亮为 accent 色。每张卡片包含名称、描述、价格（大号字体）、周期说明、绿色勾选特性列表。

### Security

双栏布局，左侧为标题 + 描述 + 2×2 安全认证徽章网格（绿色盾牌图标），右侧为垂直排列的特性行（紫色圆形勾选图标 + 标题 + 描述），每行浅灰蓝背景圆角条。

### Footer

五栏网格（品牌区 2fr + 四个链接列各 1fr），品牌区含 logo + 标语，链接列含标题 + 垂直链接列表。底部横线分隔版权信息与法律链接。

## 完整提示词 (Full Prompt)

# 设计风格：Payment-Gateway

## 设计哲学

### 核心原则

受 Stripe 等顶级支付平台启发的金融科技 SaaS 美学。追求**专业可信**与**开发者友好**的平衡——既向企业决策者传递安全感，又向开发者展示 API 的简洁优雅。设计语言根植于"清晰的信息层级 + 克制的色彩 + 精确的间距"。

### 视觉气质

**情感关键词**：
- *专业可信* — 深蓝标题与白色画布传递金融机构的稳重感
- *开发者友好* — 代码块作为视觉焦点，语法高亮暗示技术深度
- *现代简洁* — 无多余装饰，每个像素都有信息价值

**此设计不是什么**：
- 不是消费级花哨风格——没有渐变背景、没有浮动元素、没有插画
- 不是深色科技风——以白色为主画布，深色仅用于代码块和标题
- 不是极简主义——有明确的品牌色、丰富的组件层次、完整的信息密度

### 此风格的 DNA

#### 1. 渐变文字签名
"internet" 等关键词使用 `linear-gradient(135deg, #635BFF, #00D4FF)` 从靛蓝到青色的渐变填充，作为全页最醒目的视觉签名。

#### 2. 深色代码块
Hero 区右侧放置 `#0A2540` 深蓝背景的代码编辑器样式区块，含红/黄/绿三色圆点窗口控件和语法高亮，传递"开发者第一"的品牌定位。

#### 3. 蓝主色系统
`#635BFF` 作为唯一品牌色贯穿所有交互元素——按钮、徽章、链接、边框高亮、图标背景。

#### 4. 绿色成功指示
`#30D158` 用于所有正面信号——勾选图标、徽章、状态指示器，与靛蓝形成冷暖对比。

#### 5. 细边框卡片
所有卡片使用 `1px solid #E2E8F0` 细边框而非阴影来定义边界，悬停时才出现柔和阴影，保持页面干净通透。

## 设计 Token 系统（DNA）

### 色彩策略

**色彩聚焦**：以纯白为画布，深蓝为文字锚点，蓝为品牌灵魂，绿色为成功信号。整体色彩温度偏冷，对比度高但柔和。

| Token | 值 | 用法与上下文 |
|:------|:------|:----------------|
| `--bg` | `#FFFFFF` | 主背景画布 |
| `--bg-alt` | `#F6F9FC` | 交替区块背景（Features、Security） |
| `--bg-code` | `#0A2540` | 代码块深色背景 |
| `--bg-surface` | `#FFFFFF` | 卡片/面板表面 |
| `--bg-badge` | `rgba(99, 91, 255, 0.08)` | 靛蓝徽章淡底色 |
| `--border` | `#E2E8F0` | 卡片/分隔线边框 |
| `--border-light` | `#E6EBF1` | 悬停态边框 |
| `--text` | `#0A2540` | 正文文字色 |
| `--text-heading` | `#0F1740` | 标题文字色（更深蓝） |
| `--text-muted` | `#425466` | 次要/描述文字 |
| `--text-dim` | `#8898AA` | 弱化文字/页脚 |
| `--accent` | `#635BFF` | 主品牌色（靛蓝） |
| `--accent-hover` | `#524AE0` | 按钮悬停态 |

**签名渐变**：
```css
background: linear-gradient(135deg, #635BFF 0%, #00D4FF 100%);
```

### 字体系统

**字体配对**：
- **展示字体**：`Space Grotesk` — 几何无衬线，用于标题，科技感与专业感并存
- **UI/正文字体**：`DM Sans` / `Inter` — 清晰可读的无衬线，用于正文与 UI 元素
- **等宽字体**：`JetBrains Mono` — 代码块专用，语法高亮友好

**字号阶梯与用法**：

| 元素 | 尺寸 | 字体 | 字重 | 字距 | 备注 |
|:--------|:-----|:-----|:-------|:---------|:------|
| Hero 标题 | `clamp(2.5rem, 5vw, 4rem)` | Space Grotesk | 700 | -0.02em | 含渐变文字 |
| 区块标题 | `clamp(1.75rem, 3vw, 2.5rem)` | Space Grotesk | 700 | -0.01em | 居中 |
| 卡片标题 | `1.25rem` | Space Grotesk | 600 | 0 | 左对齐 |
| 正文 | `15-18px` | DM Sans | 400 | 0 | 行高 1.6-1.7 |
| 标签/徽章 | `12-13px` | DM Sans | 600 | 0.02em | 大写间距 |
| 代码 | `14px` | JetBrains Mono | 400 | 0 | 行高 1.7 |
| 统计数字 | `2rem` | Space Grotesk | 700 | 0 | 加粗突出 |

### 间距与布局

- **区块间距**：标准区块 `96px` 垂直内边距，Hero `128px 0 80px`
- **容器宽度**：`max-width: 1280px`，水平 padding `32px`
- **网格间隙**：三列 `32px`，四列 `24px`，双列 `32px`
- **卡片内边距**：`32px`
- **组件间距**：按钮组 `16px`，列表项 `14px`

**常见间距值**：`8px`, `12px`, `16px`, `20px`, `24px`, `32px`, `48px`, `64px`, `96px`, `128px`

### 边框、表面与阴影

**圆角策略**：
- 卡片/面板：`12px`
- 按钮/输入框：`8px`
- 徽章/标签：`9999px`（胶囊形）
- 代码块：`12px`

**边框**：`1px solid #E2E8F0`，统一细边框定义卡片边界

**阴影系统**：

| Token | 值 | 用法 |
|:------|:------|:------|
| `shadow-sm` | `0 1px 3px rgba(10,37,64,0.06)` | 微悬停 |
| `shadow-md` | `0 4px 12px rgba(10,37,64,0.08)` | 卡片悬停、推荐卡片 |
| `shadow-lg` | `0 8px 30px rgba(10,37,64,0.1)` | 定价卡片悬停、主题切换按钮 |

**纹理与图案**：无纹理，纯平面色块。

## "大胆要素"（签名元素）

1. **渐变文字焦点**：Hero 标题中 "internet" 使用靛蓝→青色渐变，是全页唯一彩色文字，形成强烈视觉锚点
2. **代码块即 Hero 图**：不用产品截图或插画，而是用语法高亮的代码编辑器作为右侧视觉主体，直接传达"开发者工具"定位
3. **窗口控件圆点**：代码块顶部的红/黄/绿三色圆点模拟 macOS 窗口控件，增强代码编辑器的真实感
4. **细边框而非阴影**：所有卡片默认仅用 `1px` 细边框定义边界，悬停时才出现阴影，保持页面极致干净
5. **统计数据行**：Hero 底部三列大数字（$500B+、135+、99.99%），用数据建立信任
6. **Popular 悬浮徽章**：定价卡片顶部居中的紫色 "Popular" 徽章突破卡片上边界，形成视觉层次

## 效果与动画

**运动哲学**：克制而精致。以静态布局为主，仅在交互时提供微妙反馈。

**过渡默认**：
- 标准：`0.2s cubic-bezier(0.4, 0, 0.2, 1)`
- 入场：IntersectionObserver 触发，`translateY(8px)` → `0` + `opacity 0→1`，`0.6s ease`
- 悬停：按钮上移 `1px` + 阴影加深，卡片阴影出现

**持续动画**：
- Hero 徽章绿点：`pulse` 动画，`2s ease-in-out infinite`，opacity 在 1 和 0.4 之间循环

**关键帧动画**：
```css
@keyframes pulse-dot {
  0%, 100% { opacity: 1; }
  50% { opacity: 0.4; }
}
```

## 响应式策略

**断点哲学**：以 1024px 和 768px 为关键断点，从双栏/三栏退化为单栏。

- **Hero**：桌面双栏 → 平板/手机单栏堆叠
- **Features/Pricing**：桌面三列 → 平板两列 → 手机单列
- **Security**：桌面双栏 → 平板/手机单栏
- **Footer**：桌面五栏 → 平板三栏 → 手机两栏（品牌区跨全宽）
- **导航**：桌面完整 → 手机隐藏链接（保留 logo + CTA）

**关键适配**：
- 标题使用 `clamp()` 流体字号
- 区块内边距从 `96px` 缩减至 `64px`
- 容器 padding 从 `32px` 缩减至 `20px`

## 可访问性与最佳实践

**色彩对比**：主文字 `#0A2540` 在 `#FFFFFF` 上对比度 > 15:1（AAA），次要文字 `#425466` 对比度 > 7:1（AA）。

**聚焦状态**：输入框聚焦时显示 `3px` 靛蓝光晕环。

**触控目标**：按钮最小 `44px` 高度，满足移动端触控要求。

**运动**：`prefers-reduced-motion: reduce` 时禁用所有动画与过渡，reveal 元素直接可见。

## 实现说明

- **组件结构**：单文件 HTML，零构建依赖，内联 CSS + 少量 JS
- **CSS 自定义属性**：所有设计 Token 通过 `:root` 变量定义，支持 `data-theme="dark"` 深色模式翻转
- **字体加载**：Google Fonts CDN 加载 Space Grotesk、DM Sans、JetBrains Mono
- **动画**：IntersectionObserver 实现滚动入场，纯 CSS transition 实现悬停效果
