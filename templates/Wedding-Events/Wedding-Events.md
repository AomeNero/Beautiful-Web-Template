## 完整提示词 (Full Prompt)

# Wedding & Events — Soft UI Evolution + Aurora UI 设计系统

## 设计哲学

**核心原则**：将 Soft UI Evolution 的柔和触感与 Aurora UI 的梦幻光感完美融合，打造浪漫优雅的婚礼策划体验。以奶油白（#FFFAF5）和柔和粉（#FFE8EE）为基调，通过粉色双向阴影（`rgba(232,180,184,0.15)` 右下 + `rgba(255,255,255,0.8)` 左上）让元素如云朵般轻柔浮起。金色（#D4AF37）作为精致点缀，用于标签、图标和装饰元素，传递奢华与庆典感。Cormorant Garamond 衬线字体赋予标题古典优雅气质，DM Sans 无衬线字体确保正文清晰可读。

**气质**：浪漫、优雅、温暖、可信赖。UI 感觉如精致的婚礼请柬——柔和的粉色调唤起爱情与温柔，金色点缀增添庆典的华丽感，大圆角和柔和阴影营造安全舒适的氛围。整体设计在梦幻浪漫与专业可信之间取得完美平衡。

**独特视觉签名**：
- **Soft UI 粉色双向阴影**：`rgba(232,180,184,0.15) 8px 8px 20px` + `rgba(255,255,255,0.8) -8px -8px 20px`，创造柔和的粉色光晕凸起效果。
- **奶油粉双色背景系统**：奶油白（#FFFAF5）与柔和粉（#FFF5F5 / #FFE8EE）交替使用，营造温暖浪漫氛围。
- **金色精致点缀**（#D4AF37）：用于小标签（"OUR SERVICES"）、心形图标、星级评分、装饰分隔线。
- **Cormorant Garamond 衬线标题**：古典优雅的衬线字体作大标题，字重 400-700，传递婚礼的仪式感。
- **DM Sans 正文**：现代干净的无衬线字体，字重 400-700，确保可读性。
- **粉色心形图标系统**：Logo、服务图标、装饰元素均使用粉色心形，强化品牌识别。
- **胶囊徽章**：粉色圆角胶囊用于标签和徽章（"Creating Magical Moments Since 2010"），带金色图标。
- **大圆角按钮**：50px 圆角的胶囊按钮，粉色实心或描边样式。
- **卡片 16px 圆角**：服务卡片、供应商卡片、评价卡片均使用 16px 圆角 + Soft UI 阴影。
- **图片大圆角**：画廊和供应商图片使用 16px 圆角，柔和融入页面。

## 设计 Token 系统（DNA）

### 色彩（浅色模式 — 奶油粉 + 金色）

- **Background**：`#FFFAF5` — 奶油白作为基础画布，温暖柔和。
- **Background Alt**：`#FFF5F5` — 柔和粉色作为交替区块背景。
- **Background Cream**：`#FFF8F0` — 暖奶油色用于 Services / Planning 区块。
- **Surface**：`#FFFFFF` — 纯白用于卡片背景。
- **Foreground**：`#0F172A` — 深蓝黑作主要标题文字（极少使用）。
- **Text Primary**：`#4A3728` — 深棕色作主要标题文字（衬线标题）。
- **Text Body**：`#7D6B5D` — 暖灰棕作正文文字。
- **Text Muted**：`#7D6B5D` — 中灰棕作次要文字和导航链接。
- **Accent Pink**：`#E8B4B8` — 柔和粉作主色调，用于按钮、图标、装饰。
- **Accent Pink Light**：`#FFE8EE` — 极浅粉用于徽章背景。
- **Accent Gold**：`#D4AF37` — 金色作点缀色，用于标签、图标、星级。
- **Border**：`#E2E8F0` — 浅灰边框。
- **Border Pink**：`#E8B4B8` — 粉色边框用于描边按钮和卡片。

**阴影色**（Soft UI 核心）：
- **Shadow Light**：`rgba(255,255,255,0.8)` — 纯白作左上光源阴影。
- **Shadow Dark**：`rgba(232,180,184,0.15)` — 柔和粉作右下暗影阴影。

### 字体

- **Heading Font**：`'Cormorant Garamond', serif` — 古典优雅衬线字体，用于所有标题。
- **Body Font**：`'DM Sans', sans-serif` — 现代无衬线字体，用于正文和导航。

### 字号

- **Hero Title**：`64px` / `4rem` — 超大衬线标题。
- **Section Title**：`40px` / `2.5rem` — 区块标题。
- **Card Title**：`24px` / `1.5rem` — 卡片标题。
- **Body**：`16px` / `1rem` — 正文。
- **Small**：`14px` — 小字标签。
- **Label**：`12px` — 极小标签（"OUR SERVICES" 等）。

### 圆角

- **Button**：`50px` — 胶囊按钮。
- **Badge**：`50px` — 胶囊徽章。
- **Card**：`16px` — 卡片圆角。
- **Image**：`16px` — 图片圆角。
- **Icon Circle**：`50%` — 圆形图标容器。

### 间距

- **Section Padding**：`96px 0` — 区块上下内边距。
- **Container Max Width**：`1280px` — 内容最大宽度。
- **Container Padding**：`0 32px` — 容器左右内边距。
- **Card Gap**：`32px` — 卡片间距。
- **Element Gap**：`16px` / `24px` — 元素间距。

### 阴影

```css
--shadow-soft: rgba(232, 180, 184, 0.15) 8px 8px 20px 0px,
               rgba(255, 255, 255, 0.8) -8px -8px 20px 0px;
```

## 组件样式

### 按钮

- **Primary**：粉色实心（`#E8B4B8`），白色文字，50px 圆角，padding `14px 32px`，hover 时颜色加深。
- **Outline**：透明背景，粉色边框（`#E8B4B8`），粉色文字，50px 圆角，padding `14px 32px`，hover 时背景变粉色。
- **Gold Label**：金色小字（`#D4AF37`），uppercase，letter-spacing `1.4px`，字号 `12px`。

### 卡片

- 白色背景，16px 圆角，Soft UI 粉色双向阴影。
- 顶部可选图片区域（16px 上圆角）。
- 内部 padding `24px` 或 `32px`。
- 悬停时阴影加深。

### 徽章

- 粉色背景（`#FFE8EE`），50px 圆角胶囊，padding `4px 12px` 或 `8px 16px`。
- 内含金色小图标 + 文字。

### 导航栏

- 固定顶部，白色背景，底部极淡粉色分隔线。
- 高度约 `81px`。
- Logo 区：粉色心形 SVG + 衬线品牌名。
- 导航链接：DM Sans，`#7D6B5D` 颜色，hover 变深。
- CTA 按钮：粉色实心胶囊。

### 表单

- 输入框：白色背景，浅灰边框，16px 圆角，padding `14px 16px`。
- 下拉选择：同上样式。
- 提交按钮：粉色实心胶囊，全宽或自适应。

## 签名特征总结

1. **粉色 Soft UI 阴影** — 所有可交互元素使用粉色双向阴影，创造梦幻柔和的触感。
2. **奶油粉交替背景** — 区块在奶油白（#FFFAF5）、暖奶油（#FFF8F0）和柔和粉（#FFF5F5）之间交替。
3. **金色精致点缀** — 小标签、心形图标、星级评分、装饰线均使用金色（#D4AF37）。
4. **衬线 + 无衬线字体配对** — Cormorant Garamond 标题 + DM Sans 正文，古典与现代的完美融合。
5. **心形品牌符号** — Logo、服务图标、装饰元素统一使用粉色心形，强化婚礼主题。
6. **胶囊按钮与徽章** — 50px 大圆角的胶囊形态贯穿按钮和徽章设计。
7. **大圆角图片** — 所有图片使用 16px 圆角，柔和融入页面布局。
8. **统计数据展示** — Hero 底部三列金色数字 + 灰色标签的统计数据。
9. **媒体背书行** — Footer 底部展示知名婚礼媒体 Logo（The Knot, Vogue Weddings 等）。
10. **供应商卡片系统** — 图片 + 金色分类 + 衬线名称 + 星级评分的标准化卡片。
