## 布局创意 (Layout Ideas)

### Hero

全宽近黑背景（#0d0d0d），居中对齐。顶部版本徽章胶囊（绿色圆点 + 文字），超大标题分两行（白色 + 霓虹绿），灰色副标题，双 CTA 按钮（实心绿 + 描边），下方代码安装命令条（等宽字体 + 复制图标），底部三列统计数据（绿色数字 + 灰色标签）。

### Features

三列卡片网格，每张卡片含图标（绿色方块背景）、标题、描述文字。卡片背景 #161616，1px 边框 #27272a，圆角 8px。

### Integrations

居中标题（"Works with your" 白色 + "favorite tools" 绿色）+ 灰色副标题，下方集成工具 Logo 网格。

### CTA

大圆角卡片（背景 #161616，边框 #27272a），居中内容。标题（"Ready to build" 白色 + "faster?" 绿色），灰色描述，双 CTA 按钮，底部三个绿色勾选 + 灰色文字承诺项。

### Footer

四列链接布局。左侧品牌区（Logo + 描述 + 社交图标按钮），右侧三列链接（Product / Resources / Company），底部版权信息 + 法律链接。

# 设计风格：Developer-Tools

## 设计哲学

### 核心原则

为开发者工具产品打造的暗色终端美学。以近黑画布为基底，霓虹绿（#39ff14）作为唯一强调色贯穿全局——从 CTA 按钮、数据指标、代码语法到勾选标记，形成强烈的视觉统一性。设计语言根植于开发者熟悉的 IDE 与终端环境：等宽字体代码块、macOS 窗口装饰、命令行安装提示，让目标用户一眼感到"这是为我做的"。

### 视觉气质

**情感关键词**：
- *技术自信* — 近黑背景与霓虹绿的极致对比，传递专业与前沿感
- *开发者归属* — 终端、代码编辑器、命令行等元素直接映射开发者日常工作环境
- *极简力量* — 单色强调策略，拒绝花哨装饰，让功能与代码成为视觉主角

**此设计不是什么**：
- 不是企业 SaaS 的蓝色渐变友好风
- 不是消费级产品的温暖插画叙事
- 不是数据密集型的仪表盘布局

### 此风格的 DNA

#### 1. 霓虹绿单色强调
全局仅使用 #39ff14 一种强调色，应用于 CTA 按钮、统计数字、代码关键字、勾选标记、标签文字。这种极端克制的色彩策略形成强烈的品牌识别。

#### 2. 终端式代码展示
代码块使用 JetBrains Mono 等宽字体，深色背景（#1e1e1e），语法高亮（粉色 import、黄色字符串、蓝色注释、绿色函数名），macOS 窗口装饰（红黄绿圆点）。

#### 3. 几何无衬线标题
Space Grotesk 字重 700 用于所有标题，负字距（-0.02em），大字号（Hero 标题约 64px），白色与绿色交替使用形成节奏感。

#### 4. 微边框卡片系统
所有卡片使用 1px solid #27272a 边框 + 8px 圆角，无阴影，通过边框而非阴影定义层级。

#### 5. 命令行安装提示
Hero 区域底部展示 `npm install @devkit/cli` 命令条，等宽字体，深色背景，带复制按钮，直接面向开发者用户。

## 设计 Token 系统（DNA）

### 色彩策略

**色彩聚焦**：近黑画布 + 霓虹绿单色强调 + 灰阶文字层级。整个设计仅使用一种彩色（#39ff14），其余全部为黑白灰，形成极致的终端美学。

| Token | 值 | 用法与上下文 |
|:------|:------|:----------------|
| `background` | `#0d0d0d` | 页面主背景，近纯黑 |
| `surface` | `#161616` | 卡片、代码块、CTA 卡片背景 |
| `surface-alt` | `#1e1e1e` | 代码编辑器内部背景 |
| `foreground` | `#ffffff` | 主标题、导航文字 |
| `foreground-muted` | `#71717a` | 副标题、描述文字、footer 链接 |
| `accent` | `#39ff14` | CTA 按钮、统计数字、代码关键字、勾选标记、标签 |
| `accent-text` | `#000000` | 绿色按钮上的文字颜色 |
| `border` | `#27272a` | 卡片边框、分隔线 |
| `border-nav` | `#27272a` | 导航栏底部边框 |

**签名渐变**：无渐变，纯色平铺。

### 字体系统

**字体配对**：
- **展示字体**：`Space Grotesk` — 几何感无衬线，用于所有标题，字重 500-700，负字距
- **UI/正文字体**：`DM Sans` — 现代几何无衬线，用于正文与导航，字重 400-500
- **等宽字体**：`JetBrains Mono` — 代码块与命令行，字重 400-500

**字号阶梯与用法**：

| 元素 | 尺寸 | 字体 | 字重 | 字距 | 备注 |
|:--------|:-----|:-----|:-------|:---------|:------|
| Hero 标题 | 64px | Space Grotesk | 700 | -0.02em | 白色 + 绿色交替 |
| 区块标题 | 40px | Space Grotesk | 700 | -0.02em | 白色 + 绿色交替 |
| 卡片标题 | 20px | Space Grotesk | 600 | normal | 白色 |
| 正文 | 16px | DM Sans | 400 | normal | 灰色 #71717a |
| 标签 | 12px | JetBrains Mono | 500 | 0.07em | 绿色大写 |
| 代码 | 14px | JetBrains Mono | 400 | normal | 语法高亮 |
| 导航 | 15px | DM Sans | 400 | normal | 灰色 |
| 统计数字 | 32px | Space Grotesk | 700 | -0.02em | 绿色 |

### 间距与布局

- **区块间距**：顶部 96px，底部 80px（Hero）；其他区块 80px 垂直内边距
- **容器宽度**：最大 1200px，左右 24px 内边距
- **网格间隙**：24px（卡片网格）、32px（大间距）、48px（区块间）
- **非对称模式**：Code Preview 区域左右分栏（文本左 + 代码右）

**常见间距值**：8px / 12px / 16px / 24px / 32px / 48px / 64px / 80px / 96px

### 边框、表面与阴影

**圆角策略**：
- 按钮：8px
- 卡片：8px
- 徽章/胶囊：999px（全圆角）
- 代码窗口：12px

**边框**：1px solid #27272a，用于卡片与导航分隔

**阴影系统**：无阴影设计，完全依赖边框与色彩对比定义层级

**纹理与图案**：无纹理，纯色平铺

## "大胆要素"（签名元素）

1. **霓虹绿单色统治**：全局仅一种彩色 #39ff14，从按钮到代码到统计数据到勾选标记，形成极端统一的视觉语言
2. **命令行安装条**：Hero 底部直接展示 `npm install` 命令，带复制按钮，零废话面向开发者
3. **macOS 代码窗口**：代码预览使用真实 macOS 窗口装饰（红黄绿圆点），增强开发者熟悉感
4. **无阴影纯边框层级**：完全放弃阴影，仅用 1px 边框定义卡片与表面，极简到极致
5. **标题双色节奏**：大标题中白色与绿色交替（如 "Build faster with" 白色 + "modern dev tools" 绿色），形成视觉节拍

## 效果与动画

**运动哲学**：克制、快速、功能性。无装饰性动画，仅保留必要的交互反馈。

**过渡默认**：
- 标准：`all 0.2s ease`
- 入场：从下方淡入（translateY 20px → 0，opacity 0 → 1），0.5s ease-out
- 悬停：按钮上移 1px + 亮度变化，卡片边框变亮

**持续动画**：无

**关键帧动画**：
```css
@keyframes fadeInUp {
  from { opacity: 0; transform: translateY(20px); }
  to { opacity: 1; transform: translateY(0); }
}
```

## 响应式策略

**断点哲学**：从移动端单列堆叠到桌面端多列网格，保持近黑背景与绿色强调不变。

- **Hero**：移动端标题缩小至 36px，统计改为单列垂直排列
- **Features**：三列 → 两列（768px）→ 单列（480px）
- **Code Preview**：左右分栏 → 上下堆叠（768px）
- **Footer**：四列 → 两列（768px）→ 单列（480px）

**关键适配**：
- 标题尺寸：64px → 48px → 36px
- 间距缩减：96px → 64px → 48px
- 导航链接隐藏，替换为汉堡菜单

---

## 可访问性与最佳实践

**色彩对比**：绿色 #39ff14 在 #0d0d0d 背景上对比度约 15.4:1（AAA），白色文字在绿色按钮上对比度约 16.8:1（AAA）

**聚焦状态**：绿色 2px outline + 2px offset

**触控目标**：按钮最小 44px 高度

**运动**：prefers-reduced-motion 时禁用所有动画，直接显示最终状态

## 实现说明

- **组件结构**：纯 HTML + CSS，零框架依赖
- **CSS 自定义属性**：所有色彩、字体、间距通过 :root 变量定义
- **字体加载**：Google Fonts CDN（Space Grotesk + DM Sans + JetBrains Mono）
- **动画库**：原生 CSS transitions + IntersectionObserver 入场动画
