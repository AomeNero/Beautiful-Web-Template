## 布局创意 (Layout Ideas)

### Header

固定顶部导航栏，深色半透明背景（rgba(11,15,26,0.95)）配磨砂玻璃效果与底部细边框。左侧品牌 Logo（蓝紫渐变圆角方块 + 上升趋势图标 + "Vestia" 文字），中间导航链接（Features / Markets / Pricing / Learn），右侧 Log In 文字链接 + 蓝色圆角 CTA 按钮。

### Hero

非对称双列布局。左侧：绿色 "Markets Open" 胶囊徽章（带脉冲圆点）→ 大标题（"Invest in Your Future"，"Future" 用蓝紫渐变文字）→ 描述段落 → 双按钮（主按钮蓝色填充 + 次按钮描边）→ 三列统计数据（$2.5B+ / 500K+ / 0.1%）。右侧：投资组合卡片（Portfolio Value $124,582.40 + 绿色收益 + SVG 面积图）+ 三支股票列表（AAPL / GOOGL / MSFT，含价格与涨跌幅）。

### Features

区块标题居中，带蓝色描边胶囊徽章。三列功能卡片网格：每张卡片含蓝色半透明图标背景、标题、描述文字。卡片深色背景配细边框，悬停时上移并加深边框。

### Markets

交替深色背景区块。顶部四列市场指数卡片（S&P 500 / NASDAQ / DOW / Bitcoin），等宽字体显示数值，绿色/红色标注涨跌。下方 Top Movers 数据表格：Symbol / Name / Price / Change / Action 五列，Trade 按钮为蓝色小胶囊。

### Pricing

三列定价卡片：Basic（$0）/ Pro（$9.99，featured 高亮带蓝色边框与发光阴影）/ Premium（$29.99）。每张卡片含功能列表（绿色勾选图标）+ CTA 按钮。Pro 卡片使用蓝色填充按钮，其余使用半透明按钮。

### Footer

顶部细边框分隔，五列布局：品牌区（Logo + 标语）+ Products / Company / Resources / Legal 四列链接。底部版权行 + SIPC Member / SEC Registered 认证文字。

## 完整提示词 (Full Prompt)

# 设计风格：Investment-Platform

## 设计哲学

### 核心原则

专业金融科技美学。以深邃海军蓝为画布，蓝紫渐变为核心视觉语言，传递信任、科技与增长三重信号。界面干净利落，数据清晰可读，让投资者感到专业可靠。拒绝花哨装饰，追求数据驱动的专业感。

### 视觉气质

深邃、专业、充满科技感的金融氛围。深蓝背景如交易终端的沉稳，蓝紫渐变如市场脉动的活力，等宽字体如数据流的精准。

**情感关键词**：
- *可信赖* — 深色背景传递稳重感，统计数据与认证徽章强化信任
- *专业* — 等宽字体显示金融数据，清晰的表格与卡片布局
- *增长* — 蓝紫渐变与绿色收益数字，传递积极向上的投资回报

**此设计不是什么**：
- 不是花哨的消费级应用，没有过度装饰与娱乐化元素
- 不是冷峻的银行系统，没有冰冷的表格与灰暗色调
- 不是激进的加密货币平台，没有霓虹灯与过度饱和的色彩

### 此风格的 DNA

#### 1. 蓝紫渐变签名
从 #3B82F6（科技蓝）到 #8B5CF6（活力紫）的对角线渐变，贯穿标题强调文字、Logo 图标与装饰元素，是品牌的视觉心跳。

#### 2. 深色卡片体系
所有交互卡片使用深色背景（#1F2937）配细边框（rgba(255,255,255,0.1)），圆角 12-16px，营造层次分明的信息架构。

#### 3. 等宽数据字体
JetBrains Mono 用于所有金融数据展示（价格、涨跌幅、指数数值），传递精准与专业的数据感。

#### 4. 绿红涨跌编码
绿色（#22C55E）标注正向收益，红色（#EF4444）标注负向变化，符合金融行业的通用色彩语义。

#### 5. 发光阴影效果
Pro 定价卡片与主按钮使用蓝色发光阴影（0 0 20px rgba(59,130,246,0.3)），营造科技感与重要性层级。

#### 6. 脉冲状态指示
"Markets Open" 徽章中的绿色圆点使用脉冲动画，传递实时市场状态的紧迫感与活力。

## 设计 Token 系统（DNA）

### 色彩策略

**色彩聚焦**：以深蓝为画布，蓝紫渐变为核心，绿色/红色为数据语义色。深蓝代表专业与稳重，蓝紫代表科技与活力，绿色代表增长，红色代表警示。

| Token | 值 | 用法与上下文 |
|:------|:------|:----------------|
| `bg` | `#0B0F1A` | 主背景色，深邃海军蓝 |
| `bg-alt` | `#0F1525` | 交替区块背景，略浅深蓝 |
| `bg-card` | `#1F2937` | 卡片背景色 |
| `bg-card-hover` | `#263044` | 卡片悬停背景 |
| `foreground` | `#F9FAFB` | 主文字色，近白 |
| `foreground-muted` | `#9CA3AF` | 次要文字，描述与标签 |
| `accent` | `#3B82F6` | 主强调色，科技蓝，按钮/链接/图标 |
| `accent-hover` | `#2563EB` | 按钮悬停色 |
| `accent-gradient` | `linear-gradient(135deg, #3B82F6 0%, #8B5CF6 100%)` | 品牌渐变，Logo/标题强调 |
| `border` | `rgba(255,255,255,0.1)` | 默认边框色 |
| `border-strong` | `rgba(255,255,255,0.2)` | 强调边框 |
| `success` | `#22C55E` | 正向收益/可用状态 |
| `danger` | `#EF4444` | 负向变化/警示 |

**签名渐变**：
```css
background: linear-gradient(135deg, #3B82F6 0%, #8B5CF6 100%);
```

### 字体系统

**字体配对**：
- **展示字体**：`Space Grotesk` — 几何感无衬线，用于 Hero 标题与区块标题，现代科技感
- **UI/正文字体**：`DM Sans` — 圆润友好的无衬线，用于正文、卡片内容与导航，清晰易读
- **数据字体**：`JetBrains Mono` — 等宽字体，用于金融数据（价格、涨跌幅、指数数值）

**字号阶梯与用法**：

| 元素 | 尺寸 | 字体 | 字重 | 字距 | 备注 |
|:--------|:-----|:-----|:-------|:---------|:------|
| Hero 标题 | 60px | Space Grotesk | 700 | -0.02em | 渐变文字强调关键词 |
| 区块标题 | 36px | Space Grotesk | 700 | normal | 居中对齐 |
| 卡片标题 | 20px | Space Grotesk | 700 | normal | 功能名/定价层级 |
| 数据数值 | 24-36px | JetBrains Mono | 600-700 | normal | 价格/指数/统计 |
| 正文 | 16px | DM Sans | 400 | normal | 描述文字 |
| 标签 | 14px | DM Sans | 500 | normal | 徽章/分类/元信息 |
| 导航链接 | 14px | DM Sans | 500 | normal | 导航栏文字 |

### 间距与布局

- **区块间距**：垂直内边距 96px，区块间呼吸感充足
- **容器宽度**：max-width 1280px，居中布局
- **网格间隙**：卡片网格 gap 24-32px
- **非对称模式**：Hero 区左文右图，比例约 1:1

**常见间距值**：8px / 12px / 16px / 20px / 24px / 28px / 32px / 48px / 64px / 80px / 96px

### 边框、表面与阴影

**圆角策略**：
- 按钮/徽章：9999px（胶囊形）
- 卡片：12-16px
- Logo 图标：8px

**边框**：1px solid rgba(255,255,255,0.1) 为主，featured 卡片使用 1px solid #3B82F6

**阴影系统**：

| Token | 值 | 用法 |
|:------|:------|:------|
| `shadow-sm` | `0 2px 8px rgba(0,0,0,0.3)` | 小元素 |
| `shadow-md` | `0 4px 16px rgba(0,0,0,0.4)` | 卡片 |
| `shadow-lg` | `0 8px 32px rgba(0,0,0,0.5)` | 大元素 |
| `shadow-glow` | `0 0 20px rgba(59,130,246,0.3)` | 发光效果/featured 卡片 |
| `shadow-glow-strong` | `0 0 40px rgba(59,130,246,0.6)` | 强发光效果 |

**纹理与图案**：Hero 区域有微妙的蓝色径向渐变光晕作为背景装饰。

## 效果与动画

**运动哲学**：克制、专业、有目的性。动画服务于信息传达而非装饰，入场动画采用淡入上移，悬停采用微妙的位移与阴影变化。

**过渡默认**：
- 标准：all 0.2s cubic-bezier(0.4, 0, 0.2, 1)
- 悬停：transform translateY(-2px) + shadow 加深

**持续动画**：
- `pulse`：透明度 1→0.5→1，用于 "Markets Open" 圆点指示器
- `gradient`：背景位置 0%→100%→0% 循环，用于渐变文字/背景
- `float`：translateY(0→-10px→0)，用于浮动装饰元素
- `glow`：box-shadow 强度脉动，用于 CTA 按钮

**关键帧动画**：
```css
@keyframes pulse {
  0%, 100% { opacity: 1; }
  50% { opacity: 0.5; }
}
@keyframes gradient {
  0%, 100% { background-position: 0% center; }
  50% { background-position: 100% center; }
}
@keyframes float {
  0%, 100% { transform: translateY(0px); }
  50% { transform: translateY(-10px); }
}
@keyframes glow {
  0% { box-shadow: 0 0 20px rgba(37, 99, 235, 0.3); }
  100% { box-shadow: 0 0 40px rgba(37, 99, 235, 0.6); }
}
```

## 响应式策略

**断点哲学**：移动优先，内容优先。小屏幕堆叠为单列，中等屏幕恢复网格，大屏幕展示完整布局。

- **Hero**：移动端单列堆叠（文字上/图下），桌面端双列并排
- **功能卡片**：移动端 1 列 → 平板 2 列 → 桌面 3 列
- **市场卡片**：移动端 1 列 → 平板 2 列 → 桌面 4 列
- **定价卡片**：移动端单列居中 → 桌面端 3 列并排
- **Footer**：移动端单列堆叠 → 桌面端五列并排

**关键适配**：
- Hero 标题从 60px 缩至 40px
- 区块标题从 36px 缩至 28px
- 导航链接在小屏幕隐藏（汉堡菜单）
- 装饰性渐变光晕在小屏幕减弱或隐藏

## 可访问性与最佳实践

**色彩对比**：主文字 #F9FAFB 在 #0B0F1A 背景上对比度 > 15:1，符合 AAA 标准。蓝色 #3B82F6 在深色背景上约 4.5:1，用于大文字/图标时符合 AA。

**聚焦状态**：输入框与按钮聚焦时显示蓝色外环（outline: 2px solid #3B82F6, outline-offset: 2px）。

**触控目标**：所有可交互元素最小 44x44px，按钮内边距充足。

**运动**：prefers-reduced-motion 时禁用所有动画与过渡，入场动画改为直接显示。

## 实现说明

- **组件结构**：纯 HTML + CSS，零构建依赖，单文件组件库
- **CSS 自定义属性**：所有设计 Token 定义在 :root 中，支持主题化
- **字体加载**：Google Fonts CDN 加载 Space Grotesk (400-700) + DM Sans (400-700) + JetBrains Mono (400-700)
- **动画库**：原生 CSS 动画，无外部依赖
- **图片**：使用 SVG 内联图标与 CSS 渐变，无外部图片依赖
- **图表**：Portfolio 收益曲线使用内联 SVG path 绘制
