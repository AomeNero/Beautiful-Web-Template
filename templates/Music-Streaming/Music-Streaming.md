全幅渐变背景（深绿到深紫到品红），居中大标题 "Ready to start listening?"（"listening?" 绿色高亮），副标题，双按钮 CTA，三个绿色勾选信任徽章。

### Footer

# 设计风格：Music Streaming — Melodify Dark Neon

## 设计哲学

### 核心原则

以沉浸式音乐体验为核心的深色界面设计。追求高对比、强色彩焦点与浮动层次感。拒绝扁平单调——通过环境渐变光晕、玻璃态卡片与霓虹点缀营造"深夜听歌"的氛围感。设计语言根植于音乐流媒体产品的视觉惯例（类 Spotify），但通过更丰富的渐变层次与装饰性徽章增加视觉趣味。

### 视觉气质

*沉浸* — 近黑背景消除视觉噪音，让用户聚焦于内容与交互
*活力* — 绿色主色与霓虹渐变注入能量，传递音乐的律动感
*精致* — 圆角卡片、微妙边框与半透明徽章营造高级感

**情感关键词**：
- *沉浸* — 深色画布让内容发光，如同深夜戴上耳机
- *律动* — 绿色脉冲与渐变光晕模拟音乐的节奏感
- *现代* — 干净的排版与克制的装饰传达科技感

**此设计不是什么**：
- 不是浅色/明亮风格——完全拥抱深色模式
- 不是极简主义——有丰富的渐变、徽章与装饰元素
- 不是复古/怀旧——纯粹的现代数字产品美学

### 此风格的 DNA

#### 1. 绿色脉冲主色 (#1DB954)
贯穿导航 CTA、按钮、标签、统计数据与信任徽章。作为唯一的强饱和色，在深色背景上形成强烈视觉焦点，模拟音乐播放器的"播放"状态。

#### 2. 环境渐变光晕
Hero 与 CTA 区域使用深绿→深紫→品红的多色渐变作为背景氛围，不直接作用于内容，而是营造空间深度感。

#### 3. 浮动播放器卡片
Hero 右侧的音乐播放器 mockup 作为视觉锚点，展示产品核心功能。卡片带圆角、微妙边框与内部波形可视化，上方悬浮 "Lossless Audio" 徽章，右下角悬浮 "Ad-free" 徽章。

#### 4. 圆形艺人头像网格
Artist Spotlight 区域的 6 列圆形头像排列，统一尺寸与间距，下方绿色粉丝数形成视觉节奏。

#### 5. 双色标题高亮
标题中关键词使用绿色或紫色渐变高亮（如 "every moment" 绿色、"Artists" 紫色），打破纯白标题的单调。

#### 6. 胶囊形按钮体系
所有按钮使用全圆角（pill shape），主按钮为实心绿底黑字，次按钮为描边白底白字，形成清晰的视觉层级。

#### 7. 半透明徽章系统
"Lossless Audio"、"Ad-free"、"100M+ songs available" 等徽章使用半透明深色背景 + 绿色图标，悬浮于内容之上增加层次。

## 设计 Token 系统（DNA）

### 色彩策略

**色彩聚焦**：以近黑 (#121212) 为画布，Spotify 绿 (#1DB954) 为唯一强饱和主色，辅以紫色 (#9333EA)、品红 (#FF1493)、青色 (#00D4FF)、琥珀 (#FFB800) 作为渐变与装饰点缀。整体色彩策略是"单焦点 + 环境渐变"——绿色主导交互元素，多色渐变仅用于背景氛围。

| Token | 值 | 用法与上下文 |
|:------|:------|:----------------|
| `background` | `#121212` | 页面主背景 |
| `background-elevated` | `#1E1E1E` | 卡片/播放器背景 |
| `background-nav` | `rgba(18, 18, 18, 0.9)` | 导航栏半透明背景 |
| `background-badge` | `rgba(40, 40, 40, 0.8)` | 徽章半透明背景 |
| `foreground` | `#FFFFFF` | 主文字颜色 |
| `muted` | `#B3B3B3` | 次要文字/描述 |
| `subtle` | `#666666` | 更弱的辅助文字 |
| `accent` | `#1DB954` | 主强调色（按钮/标签/统计） |
| `accent-soft` | `rgba(29, 185, 84, 0.125)` | 绿色半透明背景 |
| `accent-purple` | `#9333EA` | 紫色点缀（标题高亮/渐变） |
| `accent-purple-soft` | `rgba(147, 51, 234, 0.125)` | 紫色半透明背景 |
| `accent-pink` | `#FF1493` | 品红点缀（渐变/徽章） |
| `accent-pink-soft` | `rgba(255, 20, 147, 0.125)` | 品红半透明背景 |
| `accent-cyan` | `#00D4FF` | 青色点缀（渐变） |
| `accent-cyan-soft` | `rgba(0, 212, 255, 0.125)` | 青色半透明背景 |

**签名渐变**：
```css
/* Hero/CTA 环境渐变 */
background: linear-gradient(135deg, #121212 0%, #0D3B1F 30%, #121212 50%, #2D1B4E 70%, #4A1942 100%);

/* 标题紫色渐变文字 */
background: linear-gradient(135deg, #9333EA, #FF1493);
-webkit-background-clip: text;
-webkit-text-fill-color: transparent;
```

### 间距与布局

- **区块间距**：垂直内边距 80-100px，区块间用背景色变化或渐变分隔

- **网格间隙**：卡片网格 gap 24px，艺人头像网格 gap 32px

**常见间距值**：8px / 16px / 24px / 32px / 48px / 64px / 80px / 100px

### 边框、表面与阴影

**圆角策略**：
- 按钮/徽章：全圆角（9999px / pill shape）

**边框**：1px solid #333333（卡片），1px solid rgba(255,255,255,0.1)（分隔线）

## "大胆要素"（签名元素）

1. **环境渐变光晕背景**：Hero 与 CTA 区域使用多色渐变（绿→紫→品红）作为氛围背景，不是简单的纯色或双色渐变，而是多段式环境光效果，模拟舞台灯光。

2. **浮动播放器 Mockup**：Hero 区域右侧放置一个完整的音乐播放器 UI 卡片，包含专辑封面、曲目信息、进度条、播放控制与波形可视化，作为产品功能的视觉预览。

3. **悬浮装饰徽章**："Lossless Audio" 和 "Ad-free" 徽章以绝对定位悬浮在播放器卡片边缘，打破卡片边界，增加层次感与产品卖点展示。

4. **双色标题关键词高亮**：标题中的关键词使用不同颜色高亮——"every moment" 用绿色、"Artists" 用紫色渐变、"listening?" 用绿色，形成视觉节奏。

5. **圆形头像网格 + 绿色数据**：Artist Spotlight 使用统一圆形头像排列，粉丝数以绿色显示形成视觉锚点，传递社交证明。

6. **波形可视化装饰**：播放器卡片底部显示绿色音频波形条，作为纯装饰元素强化音乐主题。

## 效果与动画

**运动哲学**：平滑、有节奏的入场动画，模拟音乐的流动感。元素从下方淡入，带有轻微延迟交错。

**过渡默认**：
- 标准：`all 0.3s cubic-bezier(0.4, 0, 0.2, 1)`
- 入场：从 translateY(30px) + opacity(0) 到原位，持续 0.6s，交错延迟 0.1s
- 悬停：transform translateY(-4px) + 边框/颜色变化，持续 0.3s

**持续动画**（如有）：
- 波形可视化：各条高度随机波动，模拟音频播放
- 渐变光晕：极缓慢的色彩位移（可选）

**关键帧动画**：
```css
@keyframes fadeInUp {
  from { opacity: 0; transform: translateY(30px); }
  to { opacity: 1; transform: translateY(0); }
}

@keyframes waveform {
  0%, 100% { height: 8px; }
  50% { height: 24px; }
}
```

## 响应式策略

**断点哲学**：以内容优先，从单列堆叠到多列网格渐进增强。

- **Hero**：移动端单列（文字在上，播放器在下或隐藏），桌面端左右两栏
- **Artist Grid**：移动端 2 列，平板 3 列，桌面 6 列
- **Footer**：移动端单列堆叠，桌面 5 列网格
- **导航**：移动端汉堡菜单，桌面端水平链接

**关键适配**：
- Hero 标题从 64px 缩至 36px（移动端）
- 区块间距从 100px 缩至 60px（移动端）
- 播放器卡片在移动端可简化或隐藏
- 统计数据从横向排列改为纵向堆叠

## 可访问性与最佳实践

**色彩对比**：绿色 (#1DB954) 在深色背景 (#121212) 上对比度约 7.2:1，符合 WCAG AAA。白色文字在深色背景上对比度 > 15:1。

**聚焦状态**：聚焦环使用 2px solid #1DB954 + 2px offset，确保键盘导航可见。

**触控目标**：按钮最小 44x44px，导航链接间距充足。

**运动**：`prefers-reduced-motion: reduce` 时禁用所有入场动画与波形动画，保留悬停过渡。

## 实现说明

- **组件结构**：纯 HTML + CSS，无框架依赖。可使用任何现代前端框架封装。
- **CSS 自定义属性**：所有设计 Token 定义在 `:root` 中，支持主题化覆盖。
- **字体加载**：从 Google Fonts 加载 Space Grotesk (400-700) 和 DM Sans (400-700)。
- **动画库**：纯 CSS 动画 + IntersectionObserver 触发入场，无需第三方库。
