## 布局创意 (Layout Ideas)

### Header

### Hero

非对称双栏布局。左侧：黄色"CREATIVE AGENCY"徽章（带边框与硬阴影），巨型"WE CREATE BOLD EXPERIENCES"标题（"BOLD"以白字嵌入红色色块），灰色描述文字，两个 CTA（黄色"VIEW OUR WORK →"与描边"GET IN TOUCH"）。右侧：大型黄色方块（带黑色星号符号），背后层叠红色与蓝色旋转方块，创造"视觉混乱"效果。

### Portfolio Grid

2 列网格（移动 1 列）。每张卡片：顶部项目图片，底部白色信息区带粗黑边框与硬阴影。分类徽章（黄色"MOTION"或红色"UX/UI"），项目名称，右上角箭头图标方块。

### Services

全宽黑色背景区块。"WHAT WE DO"小标签（灰色），"OUR SERVICES"巨型标题（"SERVICES"以黑字嵌入黄色色块）。下方编号服务列表（01 Brand Strategy, 02 Web Design...），每项含编号（彩色）、标题、描述与箭头按钮，以白色横线分隔。

### About / Contact

黄色全宽背景。左侧巨型"LET'S CREATE SOMETHING BOLD"标题（"BOLD"白字红底），联系信息（Email / Phone / Location）。右侧白色表单容器带硬阴影，含 Name / Email / Message 输入框与黄色"SEND MESSAGE →"按钮。

### Footer

白色背景，顶部粗黑线。左侧 logo + 描述，中间 LINKS 列，右侧 SOCIAL 列。底部版权与 Privacy / Terms 链接。

## 完整提示词 (Full Prompt)

# 设计风格：Creative Agency (Brutalism + Motion-Driven)

## 设计哲学

**Creative Agency** 风格是**粗野主义（Brutalism）**与**波普艺术（Pop Art）**的数字融合，专为创意工作室、设计机构与品牌咨询公司打造。它拒绝企业 SaaS 的柔和渐变与磨砂玻璃，转而拥抱**原始、大胆、毫不妥协**的视觉语言。

**核心 DNA 与基本原则**：

1.  **三原色宣言**：调色板直接取自**包豪斯与波普艺术**——纯红（`#FF0000`）、纯黄（`#FFFF00`）、纯蓝（`#0000FF`）与纯黑（`#000000`）在纯白（`#FFFFFF`）画布上碰撞。这不是"配色方案"，而是**视觉宣言**。每种颜色都有明确角色：黄色 = CTA 与高亮，红色 = 强调与能量，蓝色 = 深度与层次，黑色 = 结构与骨架。

2.  **结构诚实（Brutalist Honesty）**：每个元素都有**可见的边界**。粗黑边框（2-3px）定义一切——按钮、卡片、输入框、导航。阴影不是柔和的光晕，而是**实心黑色偏移块**（4-8px 偏移，零模糊）。这创造了一种"印刷品"质感，仿佛页面是从纸上剪贴而成。

3.  **字体即建筑**：**Space Grotesk**（标题）以其几何感与极粗字重（700）成为视觉骨架，**DM Sans**（正文）提供清晰可读性。标题字号极端（clamp 3rem-5.5rem），行高极紧（0.9-1.0），字距极紧（-0.03em）。"BOLD"一词以**白字嵌入红色色块**成为设计签名。

4.  **动效驱动（Motion-Driven）**：虽然静态模板无法展示完整动效，但设计预留了**运动语言**——悬停时按钮机械下压（translate 覆盖阴影）、卡片抬升、徽章旋转。过渡快速利落（100-200ms），缓动直接（ease-out），创造街机般的响应感。

5.  **有组织的视觉混乱**：Hero 右侧的层叠方块（黄/红/蓝旋转堆叠）是风格的视觉签名。元素**有意重叠**、**轻微旋转**（-3deg 到 6deg），打破网格单调，但底层结构保持功能完整。

6.  **高对比节奏**：区块在白色、黑色、黄色之间切换，创造强烈的视觉节奏。Services 区块突然转入全黑背景，Contact 区块爆发为全黄——这种**色块切换**是页面的呼吸节奏。

**气质与情感基调**：
*   **大胆自信**：每个设计选择都大声宣告，不含蓄不怯懦。
*   **创意叛逆**：反企业、反模板、反无聊。为敢于不同的创意人设计。
*   **能量充沛**：高饱和色彩与粗重字体传递紧迫感与创造力。
*   **功能美学**：粗野但不粗糙，大胆但不混乱。每个元素都有目的。

**视觉签名（即时可辨之处）**：
*   **"BOLD" 红底白字**：标题中的关键词以白字嵌入红色矩形色块，是整个设计的视觉锚点。
*   **黄色 CTA 按钮**：所有主要操作按钮为亮黄色（`#FFFF00`）配粗黑边框与硬偏移阴影，悬停机械下压。
*   **层叠几何方块**：Hero 右侧黄/红/蓝三色方块旋转层叠，创造波普艺术般的视觉焦点。
*   **厚黑边框 + 硬阴影**：所有交互元素带 2-3px 黑边框与 4-8px 实心黑偏移阴影。
*   **编号服务列表**：Services 区块以彩色编号（01 红色, 02 蓝色...）+ 白字标题 + 灰色描述 + 箭头按钮的横向条目呈现。

## 设计 Token 系统（DNA）

### 色彩（三原色浅色模式调色板）

*   **Background（画布）**：`#FFFFFF`（纯白）
    *   干净的白色画布，让三原色自由碰撞。
    *   用：主页面背景、卡片内部、导航背景。

*   **Foreground（墨）**：`#000000`（纯黑）
    *   结构色。用于所有文字、边框、阴影。
    *   用：文字、边框、阴影、图标。

*   **Accent-Yellow（主操作色）**：`#FFFF00`（纯黄）
    *   最高能量色。用于所有 CTA 按钮、关键徽章、高亮区块。
    *   用：主按钮、CTA、徽章背景、Contact 区块背景、"SERVICES"高亮。

*   **Accent-Red（强调色）**：`#FF0000`（纯红）
    *   能量与焦点色。用于"BOLD"色块、logo 点缀、分类徽章、编号。
    *   用："BOLD"背景、logo 方块、MOTION 徽章变体、服务编号 01。

*   **Accent-Blue（深度色）**：`#0000FF`（纯蓝）
    *   层次与深度色。用于层叠方块、次要编号、链接悬停。
    *   用：Hero 层叠方块、服务编号 02、UX/UI 徽章。

*   **Text-Muted（次要文字）**：`#666666`（中灰）
    *   仅用于描述性文字、标签、次要信息。
    *   用：Hero 描述、服务描述、footer 链接。

*   **Services-Background**：`#000000`（纯黑）
    *   Services 区块的反转背景，创造强烈视觉节奏。

**用色规则**：
- **黄色专用于 CTA 与高亮**，不用于大面积背景（Contact 区块除外）。
- **红色用于焦点强调**，面积控制在 10% 以内。
- **蓝色用于层次与装饰**，不用于文字。
- **黑白为骨架**，所有结构元素使用。

### 字体

*   **标题字族**：`Space Grotesk`（Google Font）
    *   几何无衬线，极粗字重时具有建筑感。现代、大胆、有个性。
    *   加载：`https://fonts.googleapis.com/css2?family=Space+Grotesk:wght@400;500;600;700&display=swap`

*   **正文字族**：`DM Sans`（Google Font）
    *   清晰、友好、高可读性。与 Space Grotesk 形成粗细对比。
    *   加载：`https://fonts.googleapis.com/css2?family=DM+Sans:wght@400;500;700&display=swap`

*   **字重**：
    *   **Bold (700)**：所有标题、按钮、导航链接、徽章文字。
    *   **Medium (500)**：正文强调、小标签。
    *   **Regular (400)**：正文、描述文字、表单占位符。

*   **字号阶梯**：
    *   展示（Hero 标题）：`clamp(3rem, 8vw, 5.5rem)` — 极端尺寸。
    *   区块标题：`clamp(2rem, 5vw, 3.5rem)`。
    *   卡片标题：`1.5rem`。
    *   正文：`1rem` - `1.125rem`。
    *   小标签：`0.75rem` - `0.875rem`，全大写，宽字距。

*   **样式技巧**：
    *   **色块嵌入文字**："BOLD"以 `color: white; background: #FF0000; padding: 0 0.3em; display: inline-block` 实现。
    *   **全大写**：导航、按钮、徽章、小标签均使用 `text-transform: uppercase`。
    *   **紧字距**：标题 `letter-spacing: -0.03em`，标签 `letter-spacing: 0.1em`。
    *   **紧行高**：标题 `line-height: 0.9-1.0`，正文 `line-height: 1.6`。

### 圆角与边框

*   **圆角**：**默认 `0px`（锐利直角）**。
    *   所有按钮、卡片、输入框、徽章均为直角矩形。
    *   这是粗野主义的核心特征——拒绝柔和。

*   **边框**：**所有交互元素强制黑边框**。
    *   默认：`2px solid #000000`（按钮、卡片、输入框）。
    *   导航分隔：`3px solid #000000`（header 底部线）。
    *   区块分隔：`2px solid #FFFFFF`（Services 区块内部分隔线）。
    *   Footer 顶部分隔：`3px solid #000000`。

### 阴影与效果

*   **硬阴影（签名效果）**：偏移、实心黑阴影，**零模糊**。
    *   **按钮**：`4px 4px 0 0 #000000`
    *   **卡片**：`6px 6px 0 0 #000000`
    *   **大元素**：`8px 8px 0 0 #000000`
    *   方向：始终右下（+x, +y）。

*   **交互阴影变化**：
    *   按钮悬停：阴影增大至 `6px 6px 0 0 #000`，按钮上移 `translate(-2px, -2px)`。
    *   按钮点击：阴影缩小至 `2px 2px 0 0 #000`，按钮下移 `translate(2px, 2px)`。
    *   卡片悬停：阴影增大，卡片上移 `translateY(-4px)`。

## 组件样式原则

### 按钮

*   **形状**：锐角矩形，无圆角。
*   **主按钮（黄色 CTA）**：
    *   `background: #FFFF00; color: #000000; border: 2px solid #000; padding: 1rem 2rem;`
    *   `box-shadow: 4px 4px 0 0 #000; font-weight: 700; text-transform: uppercase; letter-spacing: 0.05em;`
    *   悬停：`transform: translate(-2px, -2px); box-shadow: 6px 6px 0 0 #000;`
    *   点击：`transform: translate(2px, 2px); box-shadow: 2px 2px 0 0 #000;`
*   **描边按钮**：
    *   `background: transparent; color: #000; border: 2px solid #000;`
    *   悬停：`background: #000; color: #fff;`

### 卡片（Portfolio）

*   **结构**：白色背景，`border: 2px solid #000`，`box-shadow: 6px 6px 0 0 #000`。
*   **图片区**：顶部全宽图片，无内边距。
*   **信息区**：底部白色区域，`padding: 1.5rem`。
*   **分类徽章**：小矩形色块（黄色或红色），`padding: 0.25rem 0.75rem`，全大写粗体小字。
*   **箭头图标**：右上角小方块带边框，内含箭头符号。
*   **悬停**：卡片上移，阴影增大。

### 输入框

*   **样式**：`border: 2px solid #000; border-radius: 0; background: #fff;`
*   **字体**：`font-family: DM Sans; font-size: 1rem;`
*   **占位符**：`color: #999;`
*   **聚焦**：`outline: none; border-color: #000; box-shadow: 4px 4px 0 0 #000;`
*   **高度**：`min-height: 3rem;` 文本域 `min-height: 8rem;`

### 导航

*   **Logo**："BRUTAL." 粗黑字体 + 红色小方块（`display: inline-block; width: 12px; height: 12px; background: #FF0000;`）。
*   **链接**：全大写，`font-weight: 700; font-size: 0.8rem; letter-spacing: 0.05em;`，悬停加下划线或背景。
*   **CTA 按钮**：黄色硬阴影按钮，固定于导航右侧。

### 徽章

*   **形状**：小矩形，无圆角。
*   **样式**：彩色背景（黄/红），`padding: 0.25rem 0.75rem; font-size: 0.7rem; font-weight: 700; text-transform: uppercase; letter-spacing: 0.1em;`
*   **用法**：行内标签（Portfolio 分类）、Hero 顶部标签（"CREATIVE AGENCY"）。

## 布局原则

*   **容器宽度**：`max-width: 1280px`，居中，两侧 `padding: 2rem`。
*   **间距**：区块垂直间距 `padding: 6rem 0`（桌面），`4rem 0`（移动）。
*   **网格**：Portfolio 用 2 列网格（移动 1 列），Services 用单列堆叠。
*   **非对称**：Hero 用 55/45 分割，左侧文字右侧视觉。
*   **色块节奏**：白 → 白 → 黑 → 黄 → 白，创造强烈视觉节拍。

## "大胆要素"（非通用性）

1.  **"BOLD" 红底白字嵌入**：标题关键词以白字嵌入红色矩形色块，`display: inline-block; background: #FF0000; color: #FFF; padding: 0 0.3em;`，是整个设计的视觉锚点。

2.  **三色层叠方块**：Hero 右侧黄/红/蓝三个大方块以不同角度旋转层叠（`transform: rotate(-3deg)` 等），创造波普艺术焦点。

3.  **黄色机械按钮**：所有 CTA 为亮黄底配硬黑阴影，悬停/点击有机械位移反馈。

4.  **黑色 Services 区块**：页面中部突然转入全黑背景，白色文字 + 黄色高亮，创造强烈对比节奏。

5.  **编号服务条目**：每项以彩色大号编号（01 红, 02 蓝）开头，配白色横线分隔，箭头按钮结尾。

6.  **厚黑边框贯穿全局**：从导航分隔线到卡片边框到输入框，2-3px 纯黑边框定义一切结构。

## 反模式（应避免之事）

*   **圆角**：不使用 `border-radius`（除极特殊情况）。直角是粗野主义的灵魂。
*   **柔和阴影**：不使用 `box-shadow` 带模糊半径。阴影必须是实心偏移块。
*   **渐变背景**：不使用线性/径向渐变。色块是纯色硬边。
*   **磨砂玻璃**：不使用 `backdrop-filter: blur()`。
*   **柔和过渡**：不使用 `ease-in-out` 或慢速动画。过渡快速直接。
*   **灰色边框**：不使用 `#ccc` 或 `#ddd` 边框。边框要么纯黑要么纯白。
*   **企业蓝/绿**：不使用 `#3B82F6` 或 `#10B981` 等现代 SaaS 色。只用三原色。

## 动画与运动

*   **质感**：机械、利落、街机感。
*   **过渡速度**：100-200ms。
*   **缓动**：`ease-out` 或 `cubic-bezier(0.2, 0, 0, 1)`。
*   **按钮交互**：
    *   悬停：上移 2px + 阴影增大 2px。
    *   点击：下移 2px + 阴影缩小 2px（机械下压感）。
*   **卡片交互**：
    *   悬停：上移 4px + 阴影增大。
*   **装饰动画**：
    *   Hero 层叠方块可缓慢浮动（`animation: float 6s ease-in-out infinite`）。
    *   星号符号可缓慢旋转。

## 响应式策略

*   **断点**：
    *   `1024px`：桌面布局（双栏 Hero，2 列 Portfolio）。
    *   `768px`：平板/大手机（单栏堆叠，导航折叠）。
*   **移动适配**：
    *   Hero：文字与视觉堆叠，层叠方块缩小或隐藏。
    *   标题字号：`clamp(2.5rem, 12vw, 5.5rem)`。
    *   Portfolio：单列。
    *   Services：编号条目堆叠。
    *   Contact：表单全宽。
    *   导航：汉堡菜单或简化链接行。
    *   按钮：全宽或自适应。

## 可访问性与最佳实践

*   **对比**：黑字白底（21:1）、白字黑底（21:1）、黑字黄底（19.6:1）均远超 WCAG AAA。
*   **聚焦状态**：`outline: 2px solid #000; outline-offset: 2px;`
*   **运动**：尊重 `prefers-reduced-motion`，禁用装饰动画。
*   **语义 HTML**：使用 `<header>`、`<nav>`、`<main>`、`<section>`、`<footer>`。
*   **触控目标**：按钮最小 44x44px。
