## 布局创意 (Layout Ideas)

### Hero

居中对称布局，顶部徽章（评分标签）+ 超大双行标题（第二行主色高亮）+ 副标题 + 双 CTA 按钮（主色填充 + 描边）+ 信任文案。下方紧跟工单预览 Mock UI 窗口，模拟真实产品界面。

### Features

3 列网格卡片布局，每张卡片含彩色图标容器（48×48，圆角 8px，淡色背景）+ 标题 + 描述。卡片带 1px 边框与柔和阴影，悬停时边框变主色并上浮 2px。

### Channels

左右双栏布局：左侧为 2×3 渠道卡片网格（Email、Live Chat、WhatsApp、Facebook、Twitter、Instagram），右侧为统一收件箱 Mock（含渠道头像组 + 消息列表）。

### AI Assistant

左右双栏布局：左侧为聊天界面 Mock（含机器人头像、在线状态、对话气泡、打字动画），右侧为功能列表（带勾选图标 + 标题 + 描述）。

### Pricing

3 列定价卡片，中间卡片为推荐方案（主色边框 + 阴影 + "Most Popular" 徽章），每张含方案名、价格、描述、功能列表、CTA 按钮。

### Footer

深色（#0F172A）全宽页脚，5 列网格（品牌 + 4 列链接），底部版权行与社交图标。

# 设计风格：Customer-Support-CRM

## 设计哲学

### 核心原则

此设计追求"友好专业"的 SaaS 客服产品气质——既不像企业软件那样冰冷严肃，也不像消费应用那样轻浮随意。它用柔和的靛蓝色调传递可信赖感，用圆润的卡片和充足的留白营造亲和力，用精确的数据展示（工单列表、渠道连接数）体现专业性。

### 视觉气质

**情感关键词**：
- *友好* — 浅薰衣草底色与圆角卡片消解了 B2B 软件的冷硬感
- *可信赖* — 靛蓝主色传递专业与稳定，深色页脚锚定权威感
- *高效* — 清晰的信息层级与工单预览暗示产品能提升团队效率

**此设计不是什么**：
- 不是深色科技风（无霓虹、无纯黑背景）
- 不是极简留白风（有充足的内容密度与功能展示）
- 不是粗野主义（所有元素都经过精心打磨与柔和处理）

### 此风格的 DNA

#### 1. 靛蓝主色体系
从 #6366F1 主色出发，衍生出 8 种淡色 tint 背景（indigo/green/purple/amber/cyan/pink/blue/red），用于图标容器、徽章、状态标签，形成统一的色彩语言。

#### 2. 产品界面 Mock 展示
Hero 下方直接嵌入工单列表 Mock UI（带红黄绿交通灯、搜索栏、头像、状态标签），让用户一眼看到产品真实形态。

#### 3. 圆润卡片系统
所有卡片统一 16px 圆角 + 1px 浅灰边框 + 柔和弥散阴影（rgba(0,0,0,0.04) 0px 4px 20px），悬停时边框变主色并轻微上浮。

#### 4. 双色字体配对
Space Grotesk 用于所有标题（几何感、现代感），DM Sans 用于正文（圆润、易读），形成清晰的视觉层级。

#### 5. 深色页脚锚定
全页浅色基调中，页脚突然切换为深海军蓝（#0F172A），形成强烈的视觉收束感，同时提供深色模式的预览。

### 字体系统

**字体配对**：
- **展示字体**：`Space Grotesk` — 几何无衬线，用于所有标题，字重 500-700，传递现代科技感
- **UI/正文字体**：`DM Sans` — 圆润无衬线，用于正文与 UI 元素，字重 400-600，传递友好亲和力

**字号阶梯与用法**：

| 元素 | 尺寸 | 字体 | 字重 | 字距 | 备注 |

| 区块标题 | clamp(28px, 2.5vw+12px, 40px) | Space Grotesk | 700 | -0.02em | 居中或左对齐 |
| 卡片标题 | 22px | Space Grotesk | 600 | normal | Feature/Channel 卡片 |

### 间距与布局

- **区块间距**：标准 96px 垂直内边距，移动端缩减至 64px
- **容器宽度**：max-width 1280px，两侧 32px padding
- **网格间隙**：Features/Pricing 24px gap，Channels 16px gap
- **卡片内边距**：32px（Feature/Pricing），16-20px（Channel）

**常见间距值**：4px / 8px / 12px / 16px / 24px / 32px / 48px / 64px / 96px

### 边框、表面与阴影

**圆角策略**：
- 大卡片：16px
- 按钮：12px
- 胶囊/徽章：100px（全圆角）
- 小元素：8px
- 头像：50%（圆形）

**边框**：1px solid #E2E8F0，悬停时变 1px solid #6366F1

## 组件样式与交互

### 按钮

**主按钮**：
- 背景：#6366F1
- 文字：白色，600 字重
- 圆角：12px（标准）/ 100px（胶囊）
- 阴影：0 4px 14px rgba(99,102,241,0.3)
- 悬停：背景变 #4F46E5，阴影加深，上浮 1px

**次按钮**：
- 背景：白色，1px #E2E8F0 边框
- 文字：#0F172A
- 悬停：边框变主色，文字变主色

**描边按钮**：
- 透明背景，1.5px 主色边框
- 悬停：填充主色，文字变白

### 卡片
- 背景：白色
- 边框：1px #E2E8F0
- 圆角：16px
- 阴影：0 4px 20px rgba(0,0,0,0.04)
- 悬停：边框变主色，阴影加深，translateY(-2px)

### 输入框
- 背景：白色
- 边框：1px #E2E8F0
- 圆角：12px
- 聚焦：边框变主色 + 3px 主色光晕

### 导航
- 毛玻璃效果：backdrop-filter blur(12px)
- 底部分隔线：1px #E2E8F0
- 链接：#64748B，悬停变 #0F172A

### 徽章/标签
- 胶囊形（100px 圆角）
- 淡色背景 + 对应色文字
- 字号 12-14px，600 字重

### 状态标签
- Open：琥珀色（#F59E0B）+ 淡琥珀背景
- Pending：青色（#06B6D4）+ 淡青背景
- Resolved：绿色（#10B981）+ 淡绿背景

## "大胆要素"（签名元素）

1. **工单预览 Mock UI**：Hero 下方直接展示产品真实界面（带交通灯窗口控件、搜索栏、工单列表），而非抽象插图，让用户立即理解产品形态。

2. **8 色 Tint 系统**：从主色衍生出 8 种功能色淡背景（indigo/green/purple/amber/cyan/pink/blue/red），统一用于图标容器、徽章、状态标签，形成丰富的色彩层次而不杂乱。

3. **统一收件箱 Mock**：Channels 区右侧展示真实的多渠道消息聚合界面，含渠道头像组（E/C/W/F 四色圆形头像重叠）、未读圆点、时间戳，直观展示产品核心功能。

4. **AI 聊天打字动画**：AI Assistant 区底部实现三点打字动画（typing dots），配合对话气泡展示 AI 实时响应感。

5. **深色页脚收束**：全页浅色调中页脚突然切换为 #0F172A 深海军蓝，形成强烈视觉锚点，同时自然过渡到深色模式。

6. **推荐定价卡浮出**：中间定价卡用主色边框 + 主色阴影 + "Most Popular" 顶部徽章三重强调，从三列中自然浮出。

## 效果与动画

**运动哲学**：克制而精致，以微交互为主，避免过度动画干扰专业感。

**过渡默认**：
- 标准：150ms cubic-bezier(0.4, 0, 0.2, 1)
- 入场：IntersectionObserver 触发，8px 上移 + 淡入，600ms
- 悬停：卡片上浮 2px + 边框变色 + 阴影加深

**持续动画**：
- 打字动画：三点上下弹跳，1.4s 循环，prefers-reduced-motion 下静止

**关键帧动画**：
```css
@keyframes typing {
  0%, 60%, 100% { transform: translateY(0); }
  30% { transform: translateY(-4px); }
}
```

## 响应式策略

**断点哲学**：以 1024px 和 768px 为两档断点，从多列网格逐步降级为单列堆叠。

- **Features/Pricing 网格**：桌面 3 列 → 平板 2 列 → 手机 1 列
- **Channels/AI 双栏**：桌面并排 → 平板/手机上下堆叠
- **Footer 网格**：桌面 5 列 → 平板 3 列 → 手机 2 列
- **Hero 按钮**：桌面横排 → 手机纵排

**关键适配**：
- 区块内边距从 96px 缩减至 64px
- 容器 padding 从 32px 缩减至 16px
- 导航链接在移动端隐藏

## 可访问性与最佳实践

**色彩对比**：主色 #6366F1 在白色背景上对比度约 4.6:1（AA 级），深色文字 #0F172A 在白色背景上对比度 >15:1（AAA 级）。

**聚焦状态**：输入框聚焦时显示 3px 主色光晕环（box-shadow）。

**触控目标**：按钮最小 40×40px，导航链接有充足 padding。

**运动**：所有入场动画实现 prefers-reduced-motion 降级（直接显示最终状态），打字动画在 reduced-motion 下静止。

## 实现说明

- **组件结构**：单文件 HTML，零构建依赖，CSS 自定义属性驱动主题
- **CSS 自定义属性**：`:root` 定义完整 Token 系统，`html[data-theme="dark"]` 覆盖实现深色模式
- **字体加载**：Google Fonts CDN 加载 Space Grotesk（400-700）+ DM Sans（400-700）
- **动画库**：纯 CSS + IntersectionObserver，无外部依赖
- **深色模式**：页脚固定深色 + 全局 data-theme 切换按钮（右下角固定）
