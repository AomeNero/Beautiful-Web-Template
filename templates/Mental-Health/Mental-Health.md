## 完整提示词 (Full Prompt)

# 设计风格：Mental-Health

## 设计哲学

### 核心原则

以"治愈感"为设计原点，追求视觉层面的情绪安抚与专业信赖。拒绝尖锐棱角、高饱和刺激色与密集排版。设计语言的根基是：圆润、呼吸感、自然色调。每一个视觉决策都应让用户感到"这个应用理解我的脆弱，并且足够专业可以帮助我"。

### 视觉气质

**情感关键词**：
- *宁静* — 薄荷绿与淡薰衣草营造自然疗愈氛围，降低视觉焦虑
- *专业信赖* — 深海军蓝文字与结构化网格传递临床级严谨感
- *温暖亲和* — 大圆角、柔和阴影与友好字体消除医疗冰冷感

**此设计不是什么**：
- 不是临床医疗仪表盘——避免冷白+蓝绿的"医院感"
- 不是冥想 App 的极简禅风——有更丰富的功能展示与商业组件
- 不是活泼的健康运动品牌——色彩更克制、节奏更舒缓

### 此风格的 DNA

#### 1. 薄荷绿主色调
出现在所有 CTA 按钮、活跃状态指示器与关键图标背景中。色值 #6DBF9E 既有自然的治愈联想，又保持足够的专业感，是整个设计的情绪锚点。

#### 2. 超圆润卡片系统
所有卡片使用 20-24px 圆角，按钮使用 50px 全圆角。配合柔和的多层阴影（非新拟态的强烈凹凸，而是轻微浮起的"云朵感"），让界面元素像抱枕一样柔软可亲。

#### 3. 深浅交替区块节奏
页面采用白色与浅蓝灰（#F0F4F8）交替的区块背景，形成视觉呼吸节奏。这种交替不仅区分功能区块，更让长页面滚动时不显单调。

#### 4. 手机模型嵌入 Hero
Hero 区域右侧嵌入一个带圆角边框的手机模型截图，展示真实 App 界面（冥想/情绪追踪界面），让用户立刻理解产品形态，同时增加视觉层次。

#### 5. 信任徽章横条
Hero 底部或 Features 上方横排 4 个信任指标（用户数、评分、合规认证、支持可用性），每个含小图标 + 数字 + 标签，用极轻的分隔线或底色区分。

**色彩聚焦**：以冷调浅灰蓝为画布，薄荷绿为唯一行动色，薰衣草紫与柔珊瑚为辅助点缀。深海军蓝用于文字与页脚，形成"轻盈-行动-沉稳"的三层色彩结构。整体色彩数量克制，确保视觉宁静。

- **区块间距**：96px（桌面），64px（平板），48px（手机）。交替区块使用背景色区分

- **网格间隙**：卡片网格 gap 32px；内容间距 gap 16-24px

### 边框、表面与阴影

**圆角策略**：极度圆润。卡片 20-24px，按钮 50px（全圆角胶囊形），头像 50%，输入框 12px，小徽章 8px。

**边框**：1px solid #E2E8F0 为主。卡片通常无边框靠阴影区分；输入框与活跃状态使用 2px accent 色边框。

**阴影系统**：

| Token | 值 | 用法 |
|:------|:------|:------|
| `shadow-sm` | `0 2px 8px rgba(15, 23, 42, 0.06)` | 小卡片、徽章 |
| `shadow-md` | `0 4px 16px rgba(15, 23, 42, 0.08)` | 功能卡片、定价卡片 |
| `shadow-lg` | `0 8px 32px rgba(15, 23, 42, 0.12)` | Hero 手机模型、悬浮态 |
| `shadow-neu` | `rgba(255,255,255,0.8) -4px -4px 10px, rgba(163,177,198,0.4) 4px 4px 10px` | 新拟态风格输入区域 |

**纹理与图案**：无显式纹理。通过柔和渐变装饰圆形（背景中的半透明 #E8F5E9 / #EDE9FE 大圆）营造层次感。

**幽灵按钮（卡片内链接）**：

## "大胆要素"（签名元素）

1. **薄荷绿渐变 CTA 按钮**：所有主要行动按钮使用薄荷绿渐变（#6DBF9E → #5AAF8E），50px 全圆角胶囊形，白色文字。这个绿色是唯一的"行动色"，在整个浅冷调页面中极为醒目。

2. **手机模型嵌入 Hero**：Hero 右侧放置一个带 24px 圆角和柔和阴影的手机截图模型，展示 App 真实界面（冥想/情绪追踪），让产品可感知。手机周围有浮动装饰元素（小圆形、叶子图标）。

3. **深浅交替区块背景**：页面纵向节奏通过白色 `#FFFFFF` 与浅蓝灰 `#F0F4F8` 交替实现，每个区块 96px 内边距。这种交替既区分功能又营造"呼吸感"。

4. **圆形图标容器配色系统**：功能卡片图标统一使用 48px 圆形容器，但按功能类型分配不同底色——薄荷绿底（情绪追踪）、薰衣草紫底（冥想）、柔珊瑚底（咨询），形成视觉分类暗示。

5. **新拟态柔和阴影**：卡片不使用硬阴影或纯扁平，而是采用多层柔和阴影（白色高光 + 灰蓝暗部），让卡片像"浮起的云朵"。输入区域有时使用内凹新拟态效果。

6. **信任徽章横条**：Hero 底部或功能区上方，4 个指标（用户数、评分、合规、支持）横排展示，每个含小图标 + 大号数字 + 小号标签，用极轻底色条承载。

## 效果与动画

**运动哲学**：缓慢、呼吸感、不刺激。所有动画时长 0.3s-0.8s，缓动函数使用 ease-out 或 cubic-bezier(0.4, 0, 0.2, 1)。避免弹跳、闪烁等活泼动效。

**过渡默认**：
- 标准：`all 0.3s cubic-bezier(0.4, 0, 0.2, 1)`
- 入场：IntersectionObserver 触发，从下方 20px 淡入（opacity 0→1, translateY 20px→0），时长 0.6s
- 悬停：卡片 translateY(-4px) + 阴影增强，按钮 translateY(-1px)

**持续动画**：
- `breathe`：4s ease-in-out infinite，元素 scale 1→1.05→1 + opacity 0.8→1→0.8，用于 Hero 装饰圆形
- `float`：6s ease-in-out infinite，translateY 0→-10px→0，用于手机模型周围浮动元素
- `gradient`：8s ease infinite，background-position 0%→100%→0%，用于 CTA 按钮微妙渐变流动

**关键帧动画**：
```css
@keyframes breathe {
  0%, 100% { opacity: 0.8; transform: scale(1); }
  50% { opacity: 1; transform: scale(1.05); }
}

@keyframes float {
  0%, 100% { transform: translateY(0px); }
  50% { transform: translateY(-10px); }
}

@keyframes gradient {
  0%, 100% { background-position: 0% center; }
  50% { background-position: 100% center; }
}

@keyframes fadeInUp {
  from { opacity: 0; transform: translateY(20px); }
  to { opacity: 1; transform: translateY(0); }
}
```

## 响应式策略

**断点哲学**：三档渐进增强。移动端（<768px）为单列堆叠布局，所有分栏变纵向；平板（768px-1024px）为两列网格；桌面（>1024px）为三列或完整分栏。导航在移动端折叠为汉堡菜单。

- **Hero**：桌面 50/50 分栏 → 平板/手机纵向堆叠，手机模型缩至 280px 宽居中
- **Features**：桌面 3 列 → 平板 2 列 → 手机 1 列
- **How It Works**：桌面 3 列 → 手机 1 列，编号徽章移至卡片左侧
- **Testimonials**：桌面 3 列 → 手机单列轮播
- **Pricing**：桌面 2 列并排 → 手机单列堆叠
- **Footer**：桌面 4 列 → 平板 2 列 → 手机单列

**关键适配**：
- Hero 标题：桌面 60px → 平板 42px → 手机 32px
- 区块内边距：桌面 96px → 平板 64px → 手机 48px
- 容器水平 padding：桌面 32px → 手机 24px
- 装饰圆形在手机上缩小或隐藏以减少视觉噪音

## 可访问性与最佳实践

**色彩对比**：主文字 #0F172A 在 #F0F4F8 背景上对比度 > 12:1（AAA）。CTA 绿色 #6DBF9E 上白色文字对比度约 3.2:1，需确保按钮文字使用深色或加大字号以满足 AA。

**聚焦状态**：所有可交互元素聚焦时显示 2px solid #6DBF9E  outline，offset 2px。输入框聚焦使用边框变色 + 外发光。

**触控目标**：按钮最小高度 44px，导航链接最小触控区 44x44px。移动端菜单链接垂直间距 ≥ 16px。

**运动**：`@media (prefers-reduced-motion: reduce)` 下禁用所有持续动画（breathe, float, gradient），入场动画改为即时显示（duration: 0.01s），悬停位移取消。

## 实现说明

- **组件结构**：单文件 HTML + 内联 CSS + 少量 vanilla JS。无需构建工具或框架。
- **CSS 自定义属性**：所有 Token 定义在 `:root`，方便主题切换。色彩、圆角、阴影、间距均使用变量。
- **字体加载**：通过 Google Fonts CDN 加载 Quicksand (400;500;600;700) + DM Sans (400;500;600;700)。使用 `display=swap` 避免 FOIT。
- **动画实现**：IntersectionObserver 监听 `.animate-on-scroll` 元素入场；CSS `@keyframes` 实现 breathe/float/gradient；`prefers-reduced-motion` 媒体查询降级。
- **响应式**：两档断点 1024px / 768px，使用 CSS Grid + Flexbox 布局，无 JS 依赖。
