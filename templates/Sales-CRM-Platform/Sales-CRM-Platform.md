## 布局创意 (Layout Ideas)

### Hero

居中对称布局。顶部信任徽章行（SOC 2 / G2 评分 / 团队数量），下方大标题使用渐变蓝色强调"Intelligent Sales CRM"，副标题灰色说明文案，双按钮 CTA（橙色主按钮 + 描边次按钮），底部小字信任说明。最下方为宽屏 Dashboard 预览卡片，带圆角和阴影。

### Pipeline / Kanban

浅灰背景区块。四列 Kanban 看板布局（New Leads / Qualified / Proposal / Closed Won），每列含标题与计数徽章，卡片展示客户名称、描述、优先级标签和金额。卡片带细边框和悬停阴影。

### Features

白色背景区块。3x2 网格功能卡片，每张卡片含彩色图标容器（不同色调的柔和背景）、标题和描述文案。图标颜色对应功能语义（蓝色=联系人、绿色=日程、琥珀=邮件、紫色=分析、粉色=活动、蓝色=安全）。

### AI Section

浅灰背景区块。左右两栏布局：左侧为 AI 功能列表（绿色勾选标记 + 文案），右侧为笔记本电脑展示图。顶部绿色"AI-Powered"徽章标签。

### Integrations

白色背景区块。6 列集成图标网格，每个集成项为带品牌色图标的卡片，展示 Google、Slack、Zapier、Microsoft、HubSpot、Salesforce。

### Pricing

浅灰背景区块。三栏定价卡片（Starter / Professional / Enterprise），中间 Professional 卡片为"Most Popular"高亮，带蓝色边框和顶部标签。每张卡片含价格、描述、功能列表和 CTA 按钮。

### CTA

蓝色全宽背景区块。居中标题、说明文案、邮箱输入框 + 白色按钮的表单，底部三个信任勾选项。

### Footer

深色背景（#1E293B）。五栏布局：品牌信息 + 社交图标、Product、Resources、Company、Legal 链接列。底部分隔线 + 版权信息 + 合规徽章。

## 设计哲学

### 核心原则

此设计追求**专业可信的商业 SaaS 气质**，通过克制的色彩系统、清晰的视觉层级和充足留白传递可靠性。设计语言根植于现代 B2B SaaS 范式：功能导向、数据驱动、用户友好。拒绝花哨装饰和过度设计，每个视觉元素都服务于转化目标。

### 视觉气质

**情感关键词**：
- *专业* — 蓝色主调传递信任与科技感，配合 SOC 2 认证徽章强化安全感
- *高效* — 清晰的卡片式布局和信息密度让功能一目了然
- *现代* — 圆角卡片、柔和阴影、渐变文字体现当代 SaaS 审美

**此设计不是什么**：
- 不是创意机构风格（无大胆排版或实验性布局）
- 不是极简主义（有充足的功能展示区块和信息密度）
- 不是暗色科技风（以白色/浅灰为主，蓝色为点缀）

### 此风格的 DNA

#### 1. 蓝色主调 + 橙色 CTA 对比
蓝色（#2563EB）贯穿品牌标识、链接和高亮，橙色（#F97316）专用于主要转化按钮，形成清晰的视觉引导路径。

#### 2. 柔和彩色图标容器
功能图标使用不同色调的 8% 透明度背景容器（蓝/绿/琥珀/紫/粉），既区分功能又保持视觉和谐。

#### 3. 卡片式信息架构
所有内容区块均采用圆角卡片 + 细边框 + 柔和阴影的组合，信息层次清晰且易于扫描。

#### 4. 渐变标题强调
Hero 标题中"Intelligent Sales CRM"使用蓝色渐变文字效果，在保持专业的同时增加视觉吸引力。

#### 5. 信任徽章系统
从 Hero 到 CTA 到 Footer，多层级信任元素（认证徽章、评分、用户数、合规标识）贯穿全页。

## "大胆要素"（签名元素）

1. **橙色 CTA 与蓝色品牌的强对比**：在整体冷色调设计中，橙色按钮（#F97316）形成强烈的视觉焦点，引导用户点击转化。

2. **五色功能图标体系**：每个功能卡片使用不同色调的柔和背景容器（蓝/绿/琥珀/紫/粉），在保持统一性的同时实现功能语义区分。

3. **渐变标题文字**：Hero 标题中"Intelligent Sales CRM"使用蓝色渐变（#2563EB → #3B82F6），在专业基调中注入现代感。

4. **Kanban 管道可视化**：四列看板布局直观展示销售流程，每张卡片含优先级标签和金额，信息密度高但视觉清晰。

5. **多层级信任系统**：从 Hero 的认证徽章、G2 评分、用户数量，到 CTA 的试用保障，再到 Footer 的合规标识，信任元素贯穿全页。

6. **毛玻璃导航栏**：sticky 导航使用 backdrop-filter: blur(12px) + 95% 不透明度白色背景，滚动时保持内容可见性。

## 效果与动画

**运动哲学**：克制而专业。以静态布局为主，仅在必要处使用微妙的入场动画和悬停反馈。

**过渡默认**：
- 标准：200ms ease-out
- 快速：150ms ease-out（按钮、链接）
- 慢速：300ms ease-out（卡片悬停）

**入场动画**：
- `.reveal` 类元素使用 IntersectionObserver 触发
- 初始状态：opacity: 0, translateY(16px)
- 可见状态：opacity: 1, translateY(0)
- 过渡：0.6s ease

**悬停效果**：
- 按钮：上移 1px + 阴影增强
- 功能卡片：上移 2px + 阴影出现
- 导航链接：颜色从灰色变为深色
- Pipeline 卡片：阴影出现

**prefers-reduced-motion**：禁用所有动画，直接显示最终状态。

## 响应式策略

**断点哲学**：以桌面端（1280px）为设计基准，平板（1024px）和移动端（768px）逐级简化布局。

- **Pipeline 看板**：桌面 4 列 → 平板 2 列 → 移动端 1 列
- **功能卡片网格**：桌面 3 列 → 平板 2 列 → 移动端 1 列
- **定价卡片**：桌面 3 列 → 平板 2 列 → 移动端 1 列
- **集成图标**：桌面 6 列 → 平板 4 列 → 移动端 3 列
- **AI 区块**：桌面左右两栏 → 平板/移动端单栏堆叠
- **Footer**：桌面 5 栏 → 平板 3 栏 → 移动端 2 栏
- **导航链接**：桌面显示 → 移动端隐藏

**关键适配**：
- 标题使用 clamp() 实现流式缩放（2.5rem ~ 4rem）
- 区块间距在移动端适当缩减
- CTA 表单在移动端改为垂直堆叠

## 可访问性与最佳实践

**色彩对比**：
- 主文字 #0F172A on #FFFFFF：对比度 ~18:1（AAA）
- 次要文字 #64748B on #FFFFFF：对比度 ~4.6:1（AA）
- 蓝色 #2563EB on #FFFFFF：对比度 ~4.6:1（AA）
- 橙色 #F97316 on #FFFFFF：对比度 ~3:1（需大号文字）

**聚焦状态**：按钮和链接使用默认浏览器焦点环，建议添加自定义 focus-visible 样式。

**触控目标**：按钮最小 44x44px，导航链接有充足点击区域。

**运动**：实现 `prefers-reduced-motion: reduce` 降级，禁用所有动画和过渡。

## 实现说明

- **组件结构**：单文件 HTML，零构建依赖。使用 CSS 自定义属性实现 Token 系统。
- **CSS 自定义属性**：所有颜色、间距、圆角、阴影均通过 `:root` 变量定义，便于主题化。
- **字体加载**：Google Fonts 加载 Space Grotesk（300-700）和 DM Sans（300-700）。
- **动画**：纯 CSS 过渡 + IntersectionObserver 触发入场动画，无外部动画库依赖。
- **响应式**：使用 CSS Grid + clamp() + 媒体查询实现三档响应式布局。
